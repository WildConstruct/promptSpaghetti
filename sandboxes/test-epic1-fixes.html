Epic1 UI Fixes - Test Cases

🔧 Applied Fixes

1. Output Node Handle Visibility
The green output node handle was showing even when nothing was connected.
// Added connection detection using useStore hook
const hasConnection = useStore((state) => {
  const edges = state.edges;
  return edges.some(edge => edge.target === id);
});

// Handle only visible when connected or on hover
opacity: hasConnection ? 1 : 0
✅ Expected: Handle only shows when connected, or fades in on hover
2. Weight Dial Event Propagation
When clicking/dragging weight dials, the entire node was moving.
// Added stopImmediatePropagation to prevent node dragging
e.nativeEvent.stopImmediatePropagation();

// Wrapped RadioDial in protective div
<div onMouseDown={(e) => {
  e.stopPropagation();
  e.nativeEvent.stopImmediatePropagation();
}}>
✅ Expected: Dials adjust weight without moving the node
3. Drag Handle Functionality
The drag handles (⋮⋮) for reordering options weren't working.
// Fixed drag event handling
- Removed preventDefault() from dragStart (was breaking HTML5 DnD)
- Changed row cursor from 'grab' to 'default'
- Added proper dragging state styling
- Simplified drag handle implementation
✅ Expected: Options can be reordered by dragging the handles
