## Story

**As a** prompt author managing large collections of extras and assets,
**I want** automatic metadata extraction and intelligent asset matching powered by LLMs,
**so that** I can maintain consistency across hundreds of background characters and quickly find appropriate assets without manual tagging.

## Business Value

- **Scale Enablement**: Manages metadata for 1000+ extras automatically
- **Continuity Assurance**: Maintains consistency across scenes
- **Asset Discovery**: Intelligent matching reduces search time 80%
- **Production Ready**: Foundation for wardrobe/prop management
- **SAG-Forward**: Audit trails and consent tracking built-in

## Acceptance Criteria

### 1. Automatic Metadata Extraction

- On segment save/edit completion (debounced 1 second)
- Background LLM extraction of key metadata:
  ```json
  {
    "subject": "sports car",
    "action": "drifting",
    "location": "desert",
    "mood": "intense",
    "intensity": 8,
    "tags": ["vehicle", "action", "outdoor"],
    "color_palette": ["sandy", "orange", "blue"],
    "time_of_day": "sunset",
    "camera_angle": "wide",
    "style_hints": ["cinematic", "dramatic"]
  }
  ```
- Metadata stored on segment but hidden from main UI
- Accessible via inspector "Metadata" tab
- No user intervention required

### 2. Asset Browser Intelligence

- Asset browser shows "Smart Match" button
- Analyzes current segment/node metadata
- Returns ranked asset suggestions:
  - Exact matches (same tags)
  - Semantic matches (related concepts)
  - Style matches (similar mood/palette)
- Shows match confidence percentage
- Example:
  ```
  Searching for "desert scene" finds:
  - desert_sunset_01.psg (95% - exact location match)
  - arid_landscape.psg (82% - semantic match)
  - warm_tones_outdoor.psg (67% - palette match)
  ```

### 3. Continuity Tracking System

- Each extra gets persistent metadata profile:
  ```json
  {
    "extra_id": "extra_0047",
    "wardrobe": ["business_casual", "blue_shirt"],
    "appearance": ["tall", "glasses"],
    "last_action": "walking",
    "last_position": "background_left",
    "scene_history": ["scene_12", "scene_15"]
  }
  ```
- Warn when continuity breaks:
  - Wardrobe changes without scene break
  - Position jumps illogically
  - Action inconsistencies
- One-click fix suggestions

### 4. Smart Grouping & Categorization

- Background analysis groups similar segments
- Suggests node consolidation opportunities
- Auto-categories for asset organization:
  - By scene type (urban, nature, indoor)
  - By mood (tense, calm, chaotic)
  - By participant count (solo, small group, crowd)
- Visual clustering in asset browser

### 5. Scene Consistency Validation

- "Validate Scene" button on graph toolbar
- Checks all metadata for conflicts:
  - Time of day mismatches
  - Weather inconsistencies
  - Palette clashes
  - Style mixing (realistic vs stylized)
- Generates report with fix suggestions
- Traffic light indicators (green/yellow/red)

### 6. Metadata-Driven Search

- Advanced search with natural language:
  - "Find all tense urban scenes"
  - "Show warm outdoor assets"
  - "Get all extras in business attire"
- Converts query to metadata filters
- Returns ranked results with relevance scores
- Search history and saved queries

### 7. Bulk Metadata Operations

- Select multiple segments/nodes
- "Extract Metadata" batch operation
- "Apply Style" to multiple selections
- "Sync Metadata" across similar nodes
- Progress bar for large operations
- Cancelable with partial completion

### 8. Metadata Export & Import

- Export metadata as JSON alongside graphs
- Import metadata from previous projects
- CSV export for production tracking
- Includes:
  - Timestamp of extraction
  - Source (LLM model used)
  - Confidence scores
  - Edit history

### 9. Consent & Attribution Tracking

- Optional consent flags on metadata:
  ```json
  {
    "consent": {
      "data_usage": true,
      "attribution_required": false,
      "source": "original",
      "license": "CC-BY-4.0"
    }
  }
  ```
- Visual indicators for consent status
- Filter by consent in asset browser
- Export audit trail for compliance

### 10. Performance & Efficiency

- Metadata extraction: <500ms per segment
- Batch operations: 10 segments/second
- Search results: <200ms for 1000 assets
- Background processing doesn't block UI
- Metadata cache persists between sessions
- Total metadata storage: <1KB per segment

## Technical Implementation

### Metadata Service Architecture

```typescript
// packages/core/services/metadata/MetadataService.ts
export class MetadataService {
  private llmService: LLMService;
  private cache: MetadataCache;

  async extractMetadata(text: string): Promise<Metadata> {
    const cached = this.cache.get(text);
    if (cached) return cached;

    const metadata = await this.llmService.extract({
      text,
      schema: METADATA_SCHEMA,
      model: 'anthropic/claude-haiku' // Good for classification
    });

    this.cache.set(text, metadata);
    return metadata;
  }

  async matchAssets(metadata: Metadata): Promise<AssetMatch[]> {
    // Vector similarity search
    const embeddings = await this.getEmbeddings(metadata);
    return this.searchSimilar(embeddings);
  }
}
```

## Risks & Mitigations

- **Risk**: Incorrect metadata impacts search
  - **Mitigation**: Manual override, confidence scores, user feedback loop
- **Risk**: Privacy concerns with metadata
  - **Mitigation**: Local processing option, no PII extraction, clear consent
- **Risk**: Performance with large datasets
  - **Mitigation**: Indexed search, background processing, pagination
- **Risk**: Continuity false positives
  - **Mitigation**: Adjustable sensitivity, ignore options, learning from corrections
