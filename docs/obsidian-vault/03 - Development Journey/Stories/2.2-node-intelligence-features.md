## Story
**As a** prompt author working with the node graph,
**I want** intelligent assistance features embedded in nodes that help me populate choices, optimize weights, and refine text,
**so that** I can create richer, more varied prompts quickly without manual brainstorming or leaving the familiar node interface.

## Business Value
- **Demo Magic**: "Populate Choices" button creates instant "wow" moments
- **Creative Amplification**: Helps users overcome creative blocks
- **Time Savings**: Reduces prompt iteration from minutes to seconds
- **Quality Improvement**: Intelligent suggestions based on context
- **Fundraising Hook**: Shows AI enhancing creativity, not replacing it

## Acceptance Criteria

### 1. Populate Choices for WeightedChoice Nodes
- Add "Populate Choices" button in WeightedChoice inspector panel
- Button appears when node has <3 choices or on new nodes
- On click:
  - Analyze segment text and full prompt context
  - Generate 5-10 contextually relevant variations
  - Auto-assign weights based on likelihood/appropriateness
- Display loading spinner during generation (~1-2 seconds)
- Results appear as editable choices user can modify/delete
- Example:
  ```
  Input: "drifting car"
  Output: [
    {"text": "aggressively sliding sideways", "weight": 8},
    {"text": "controlled power slide", "weight": 7},
    {"text": "spinning out dramatically", "weight": 4},
    {"text": "smoothly drifting around corner", "weight": 6},
    {"text": "tire-smoking slide", "weight": 5}
  ]
  ```

### 2. Optimize Weights Based on Context
- Add "Optimize Weights" button next to existing choices
- Analyzes:
  - Choice relevance to prompt context
  - Desired variation distribution
  - Semantic similarity between choices
- Suggests new weight values (1-10 scale)
- Shows before/after preview
- One-click apply or manual adjustment
- Maintains user overrides as "locked" weights

### 3. Text Refinement (Expand/Contract/Correct)
- Add "Refine" button with dropdown in TextBlock nodes
- Three modes:
  - **Expand**: Add descriptive details and variations
  - **Contract**: Reduce to essential elements
  - **Correct**: Fix grammar/consistency issues
- Preserves variables (e.g., `{reaction}`) during refinement
- Shows diff view of changes
- Examples:
  ```
  Expand: "car drifting" → "sleek sports car aggressively drifting with tire smoke"
  Contract: "beautiful golden sunset casting long shadows" → "golden sunset, long shadows"
  Correct: "the car drift quick" → "the car drifts quickly"
  ```

### 4. Preview Variations Generator
- Add "Generate Previews" button in Output nodes
- Creates 3-5 example outputs using current graph
- Applies different random seeds and weight selections
- Shows how prompts vary with current configuration
- Helps users understand randomization impact
- Format:
  ```
  Preview 1: "Extra #23 diving behind concrete barrier from explosion"
  Preview 2: "Extra #23 running away frantically from explosion"
  Preview 3: "Extra #23 freezing in shock from explosion"
  ```

### 5. Intelligent Split Suggestions
- When user selects text spanning multiple concepts
- "Smart Split" button appears in toolbar
- Analyzes selection for natural break points
- Suggests 2-3 ways to split into segments
- Example:
  ```
  Selection: "desert scene at sunset with drifting car"
  Suggestions:
  - [desert scene] [at sunset] [with drifting car]
  - [desert scene at sunset] [with drifting car]
  ```

### 6. Conflict Detection & Resolution
- Background analysis on graph save
- Detects:
  - Contradictory descriptions in connected nodes
  - Incompatible variable values
  - Circular logic in flows
- Shows warning icon on problematic nodes
- Hover reveals issue and suggested fix
- One-click resolution or ignore

### 7. Inspiration Mode for Empty Nodes
- Empty WeightedChoice nodes show "Need inspiration?" prompt
- Analyzes upstream context
- Suggests 3 thematic directions
- Example for "urban scene" context:
  ```
  Suggestions:
  - Crowd reactions (panic, curiosity, indifference)
  - Environmental details (debris, smoke, sirens)
  - Time variations (dawn, noon, dusk, night)
  ```

### 8. Smart Merge Suggestions
- When multiple similar nodes exist
- "Merge Similar" button in graph toolbar
- Identifies nodes with >70% semantic similarity
- Suggests consolidation with combined weights
- Preview before applying
- Maintains node IDs for compatibility

### 9. Performance & UX
- All intelligent features complete in <2 seconds
- Clear loading states with progress indicators
- Cancel button for long operations
- Results appear inline without modal dialogs
- Smooth animations for result insertion
- Undo support for all operations

### 10. Intelligence Controls
- Global toggle: "Enable Intelligent Assistance"
- Per-node opt-out via context menu
- Confidence indicators on suggestions (high/medium/low)
- "Why this suggestion?" tooltips with reasoning
- Manual trigger only (no auto-suggestions)

## Technical Implementation

### Node Enhancement Integration
```typescript
// In WeightedChoiceEditor.tsx
const handlePopulateChoices = async () => {
  setLoading(true);
  const context = getFullPromptContext();
  const suggestions = await llmService.populateChoices({
    segment: nodeData.text,
    context: context,
    count: 7,
    model: 'deepseek/deepseek-r1:free'
  });
  
  // Format: [{text: string, weight: number}]
  setChoices(suggestions);
  setLoading(false);
};
```

### LLM Prompts (System)
```javascript
// Populate Choices
"Given the text segment '{segment}' in context of '{context}', 
suggest 5-10 variations that maintain the same intent but vary in 
style, intensity, or specific details. Output JSON only:
{choices: [{text: 'variation', weight: 1-10}]}"

// Optimize Weights  
"Analyze these choices in context and suggest optimal weights (1-10) 
based on variety and relevance. Higher weights for more likely/appropriate options:
Choices: {choices}
Context: {context}
Output JSON: {weights: [number, number, ...]}"

// Refine Text
"[MODE: {expand|contract|correct}] the following text while preserving 
any {variables} in curly braces. Be concise and visual.
Text: {text}
Output JSON: {refined: 'text', changes: ['change1', 'change2']}"
```

### Caching Strategy
- Cache populate suggestions by segment hash (5 min TTL)
- Cache weight optimizations by choice set (10 min TTL)
- Cache refinements by text+mode (15 min TTL)
- Skip cache when context significantly changes

### UI Components
```typescript

- SuggestionsList.tsx (displays LLM results)
- DiffViewer.tsx (shows text changes)
- ConfidenceIndicator.tsx (high/med/low)
```

## Demo Scenarios

### Scenario 1: Quick Prompt Enhancement
1. User creates WeightedChoice node for "character reaction"
2. Clicks "Populate Choices"
3. System generates: "screaming", "running", "ducking", "frozen in fear"
4. User adjusts weights, adds custom option
5. Graph produces varied realistic reactions

### Scenario 2: Complex Scene Refinement
1. User has verbose description in TextBlock
2. Selects "Contract" refinement
3. System reduces 50 words to 15 essential tokens
4. Maintains all variables and key visual elements
5. Saves tokens for generation pipeline

### Scenario 3: Crowd Variety at Scale
1. User building 100 extras for scene
2. Creates base WeightedChoice for actions
3. "Populate" generates 10 varied behaviors
4. "Optimize Weights" distributes for realism
5. Each extra gets contextually appropriate action

## Success Metrics
- Feature adoption: >70% of users try "Populate" in first session
- Suggestion acceptance: >60% of LLM suggestions kept/modified
- Time savings: 50% reduction in prompt creation time
- Quality: 80% of suggestions rated helpful by users
- Performance: 95% of operations complete in <2 seconds

## Risks & Mitigations
- **Risk**: Poor quality suggestions
  - **Mitigation**: Context-aware prompts, user can always edit/reject
- **Risk**: Feature discovery
  - **Mitigation**: Prominent buttons, first-use tooltips, empty state prompts
- **Risk**: Over-reliance on AI
  - **Mitigation**: Manual mode always available, suggestions not automatic
- **Risk**: Latency impacts workflow
  - **Mitigation**: Async operations, cancel buttons, aggressive caching
