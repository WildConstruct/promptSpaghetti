# Story 6.4: Intelligent Wire-Node Interactions

## Status

Draft

## Story

**As a** user of the prompt-spaghetti application,
**I want** intelligent drag-and-drop functionality that allows me to insert nodes directly into existing connections,
**so that** I can quickly modify graph structure by splicing or replacing connections without manual rewiring.

## Acceptance Criteria

1. **Wire Hover Detection System**: Application detects when nodes are dragged over existing edges with efficient hit-testing, visual highlighting, and proximity-based feedback during drag operations

2. **Drop Zone Visual Feedback**: System provides clear visual indicators including pulsing wire highlights, insertion point markers, and temporary edge previews to show where node insertion will occur

3. **Contextual Menu System**: When dropping a node on a wire, application presents a contextual menu with "Splice" (insert node into connection) and "Replace" (delete edge and position node for manual connection) options

4. **Wire Operations Implementation**: System performs atomic splice operations (creating two new edges through the dropped node) and replace operations (deleting edge and positioning node optimally) with proper state management

5. **Undo/Redo Support**: All wire operations are properly integrated with the undo/redo system through atomic transactions, storing complete before/after states for reliable restoration

6. **Performance & Polish**: Feature includes efficient rendering for large graphs, smooth animations, keyboard navigation support, and comprehensive error handling for edge cases

### Technical Implementation Strategy

**Hit-Testing Algorithm Design:**

```typescript
interface WireHitTest {
  detectProximity(nodePosition: { x: number; y: number }, edge: Edge): number;
  findClosestPoint(
    nodePosition: { x: number; y: number },
    edge: Edge
  ): { x: number; y: number };
  isWithinThreshold(distance: number, threshold: number): boolean;
}
```

**Edge Geometry Calculations:**

- **Distance to Line Segment**: Calculate perpendicular distance from point to edge path
- **Closest Point**: Find point on edge path closest to dragged node center
- **Threshold Detection**: Configurable proximity threshold with visual feedback scaling
- **Curved Edge Support**: Handle Bezier curves and custom edge paths properly

**Contextual Menu Positioning:**

```typescript
interface ContextMenuOptions {
  position: { x: number; y: number };
  operations: ('splice' | 'replace' | 'cancel')[];
  onSelect: (operation: string) => void;
  onCancel: () => void;
}
```

### Performance Considerations

**Hit-Testing Optimization:**

- **Spatial Indexing**: Divide canvas into grid cells for efficient edge lookup
- **Distance Caching**: Cache distance calculations during drag operations
- **Threshold Early Exit**: Skip expensive calculations when node is far from any edges
- **Edge Culling**: Only test edges currently visible in viewport

**Rendering Performance:**

- **Selective Updates**: Only re-render edges that change highlight state
- **Animation Batching**: Group animation updates using requestAnimationFrame
- **Memory Management**: Clean up event listeners and animation frames properly
- **Large Graph Handling**: Graceful degradation for graphs with 500+ edges
