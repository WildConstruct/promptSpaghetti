## Acceptance Criteria

### 1. Text Refinement (Expand/Contract/Correct)

- Add "Refine" dropdown button in TextBlock nodes
- Three modes with distinct operations:
  - **Expand**: Add descriptive details and variations
  - **Contract**: Reduce to essential elements (token optimization)
  - **Correct**: Fix grammar/consistency issues
- Preserves all variables (e.g., `{reaction}`) during refinement
- Shows diff view of changes before applying
- Supports batch refinement across multiple nodes
- Examples:
  ```
  Expand: "car drifting" → "sleek sports car aggressively drifting with tire smoke"
  Contract: "beautiful golden sunset casting long shadows" → "golden sunset, long shadows"
  Correct: "the car drift quick" → "the car drifts quickly"
  ```

### 2. Preview Variations Generator

- Add "Generate Previews" button in Output nodes
- Creates 3-5 example outputs using current graph configuration
- Applies different random seeds and weight selections
- Shows side-by-side comparison of variations
- Exports preview set for documentation
- Helps users understand randomization impact
- Format:
  ```
  Preview 1: "Extra #23 diving behind concrete barrier"
  Preview 2: "Extra #23 running away frantically"
  Preview 3: "Extra #23 freezing in shock"
  ```

### 3. Conflict Detection & Resolution

- Background analysis triggered on graph save
- Detects multiple conflict types:
  - Contradictory descriptions in connected nodes
  - Incompatible variable values
  - Circular logic in flows
  - Style inconsistencies (formal vs casual)
- Shows warning icon on problematic nodes
- Hover reveals detailed issue explanation
- Suggests resolution with confidence score
- One-click fix or ignore with reason logging

### 4. Smart Merge Suggestions

- "Analyze Graph" button in toolbar
- Identifies nodes with >70% semantic similarity
- Groups mergeable nodes visually
- Suggests consolidation strategies:
  - Combine into single WeightedChoice
  - Create shared variable
  - Extract to reusable fragment
- Preview graph before and after merge
- Maintains all node IDs for compatibility
- Undo supports full graph restoration

### 5. Intelligent Split Suggestions

- When user selects text spanning multiple concepts
- "Smart Split" button appears in selection toolbar
- AI analyzes for natural semantic boundaries
- Suggests 2-3 split strategies with rationale
- Preview how splits affect graph flow
- One-click apply with automatic edge reconnection
- Example:
  ```
  Selection: "desert scene at sunset with drifting car"
  Suggestion 1: [setting] + [time] + [action]
  Suggestion 2: [environment] + [subject]
  Suggestion 3: [full scene] (no split recommended)
  ```

### 6. Graph Complexity Analysis

- "Analyze Complexity" report on demand
- Metrics include:
  - Node count by type
  - Average branching factor
  - Depth of randomization layers
  - Estimated output variations
- Suggestions for optimization:
  - "Consider merging nodes 5 & 7"
  - "Add weight variation to node 12"
  - "Extract common pattern to fragment"
- Export report as PDF for documentation

### 7. Collaborative Suggestions

- When multiple users edit same graph
- AI detects potential conflicts in real-time
- Suggests merge strategies for parallel edits
- "Accept theirs", "Accept mine", "Merge both" options
- Maintains edit history with attribution

### 8. Performance Optimizations

- Lazy loading of intelligence features
- Background processing doesn't block UI
- Incremental analysis on large graphs
- Client-side caching of analysis results
- WebWorker for heavy computations

## Technical Implementation

### Advanced Analysis Engine

```typescript
// GraphAnalyzer.ts
export class GraphAnalyzer {
  async detectConflicts(graph: Graph): Promise<Conflict[]> {
    const conflicts = [];

    // Semantic analysis
    for (const [node1, node2] of getConnectedPairs(graph)) {
      const similarity = await this.checkSemantic(node1, node2);
      if (similarity.hasConflict) {
        conflicts.push({
          type: 'semantic',
          nodes: [node1.id, node2.id],
          description: similarity.description,
          suggestion: similarity.resolution
        });
      }
    }

    // Circular dependency check
    const cycles = detectCycles(graph);
    conflicts.push(...cycles.map(formatCycleConflict));

    return conflicts;
  }
}
```

### Refinement Service

```typescript
// TextRefinementService.ts
export class TextRefinementService {
  async refine(
    text: string,
    mode: 'expand' | 'contract' | 'correct'
  ): Promise<RefinementResult> {
    // Preserve variables first
    const { cleaned, variables } = extractVariables(text);

    const refined = await llmService.refine({
      text: cleaned,
      mode,
      preserveStyle: true,
      maxTokens: mode === 'contract' ? 50 : 200
    });

    // Restore variables
    const final = restoreVariables(refined, variables);

    return {
      original: text,
      refined: final,
      changes: diffText(text, final),
      tokenSavings: countTokens(text) - countTokens(final)
    };
  }
}
```
