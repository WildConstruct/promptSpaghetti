# Story 2.7: Node Flip Animation for Metadata Display

## Status

✅ COMPLETE - Integrated and exported for use

## Story

**As a** user inspecting my prompt graph,
**I want** to flip nodes to reveal metadata on the back via Alt+click (power users) or a flip button in edit mode (standard users),
**So that** I can quickly inspect rich metadata without cluttering the main graph view.

## Business Value

- **Improved UX**: Clean separation between operational view and metadata inspection
- **Power User Support**: Alt+click for experienced users who want quick access
- **Standard User Accessibility**: Edit mode button ensures all users can access feature
- **Reduced Clutter**: Main graph view remains clean and focused on connections
- **Professional Feel**: 3D flip animation adds polish similar to high-end creative tools

## Acceptance Criteria

### 1. Trigger Methods

- **Power User Mode**: Alt+click on any node in normal graph view
- **Standard User Mode**: Flip button/icon visible in node edit state
- **Mobile/Touch**: Long-press gesture (no Alt key available)
- Both methods trigger the same flip animation
- Visual tooltip on hover explaining Alt+click option (optional via settings)
- Tooltip dismissible to avoid clutter for experienced users

### 2. 3D Flip Animation

- CSS `transform: rotateY(180deg)` with perspective
- Smooth transition duration: 300ms
- `transform-style: preserve-3d` for proper 3D effect
- Back face properly hidden during flip
- Animation performance optimized (GPU acceleration)

### 3. Metadata Display (Back Side)

- **Extracted Metadata Section**:
  - Themes (with clickable confidence scores for details)
  - Entities (characters, locations, objects)
  - Style indicators
  - Temporal information
  - Auto-refresh if node content changes while flipped
- **Performance Metrics**:
  - Token usage (input/output)
  - Execution time
  - Cache hit rate
- **Continuity Tracking** (if applicable):
  - Version history (with virtual scrolling for long lists)
  - Related nodes
  - Consistency warnings (non-intrusive badges)
- **Audit Trail**:
  - Last modified
  - Creation timestamp
  - Modification count
- **Fallback Display**:
  - "No metadata available" message if data unavailable

### 4. Layout and Design

- Clean, card-based design with sections
- Icons for each metadata category
- Collapsible sections for long content
- Consistent color coding with node type
- Dark/light theme support

### 5. Interaction Behavior

- Click anywhere on flipped card to flip back
- ESC key flips back any flipped nodes
- Edit mode remains accessible while flipped
- Multiple nodes can be flipped simultaneously
- Flipped state resets on graph reload (not persisted)

### 6. Accessibility

- Screen reader announces "Metadata view" when flipped
- Keyboard navigation support (Tab to focus, Enter to flip)
- High contrast mode compatible
- Focus trap when flipped for keyboard users

### 7. Performance Requirements

- Flip animation completes in <300ms
- No lag when flipping multiple nodes (batch animations if >10)
- Metadata loads instantly (pre-cached)
- Smooth animation even with 50+ nodes visible
- Temporary zoom-out or reposition for edge nodes to prevent clipping

## Technical Implementation

### Component Structure

```typescript
// packages/core/components/nodes/FlippableNode.tsx
interface FlippableNodeProps {
  node: Node;
  isFlipped: boolean;
  onFlip: () => void;
  children: React.ReactNode; // Front content
  metadata: NodeMetadata; // Back content
}

export const FlippableNode: React.FC<FlippableNodeProps> = ({
  node,
  isFlipped,
  onFlip,
  children,
  metadata
}) => {
  const handleAltClick = (e: React.MouseEvent) => {
    if (e.altKey) {
      e.preventDefault();
      onFlip();
    }
  };

  // Handle long-press for mobile
  const handleLongPress = useLongPress(onFlip, {
    threshold: 500,
    cancelOnMovement: true
  });

  return (
    <div
      className="flippable-node-container"
      onClick={handleAltClick}
      {...handleLongPress}
      aria-expanded={isFlipped}
      aria-label={isFlipped ? "Metadata view" : "Node view"}
    >
      <div className={`flippable-node ${isFlipped ? 'flipped' : ''}`}>
        <div className="node-front">
          {children}
          {isEditMode && <FlipButton onClick={onFlip} aria-label="Flip to metadata" />}
        </div>
        <div className="node-back">
          <MetadataDisplay
            metadata={metadata}
            onClose={onFlip}
            nodeId={node.id}
          />
        </div>
      </div>
    </div>
  );
};
```

// packages/core/components/nodes/MetadataDisplay.tsx
interface MetadataDisplayProps {
  metadata: NodeMetadata;
  onClose: () => void;
}

export const MetadataDisplay: React.FC<MetadataDisplayProps> = ({
  metadata,
  onClose,
  nodeId
}) => {
  // Auto-refresh metadata when node content changes
  const { nodeContent } = useNodeContent(nodeId);
  const [displayMetadata, setDisplayMetadata] = useState(metadata);

  useEffect(() => {
    if (nodeContent) {
      // Refresh metadata if content changed
      refreshMetadata(nodeId).then(setDisplayMetadata);
    }
  }, [nodeContent, nodeId]);

  if (!displayMetadata || Object.keys(displayMetadata).length === 0) {
    return (
      <div className="metadata-display metadata-empty">
        <header className="metadata-header">
          <h3>Node Metadata</h3>
          <button onClick={onClose} aria-label="Close metadata">×</button>
        </header>
        <div className="empty-message">No metadata available</div>
      </div>
    );
  }

  return (
    <div className="metadata-display">
      <header className="metadata-header">
        <h3>Node Metadata</h3>
        <button onClick={onClose} aria-label="Close metadata">×</button>
      </header>

      <CollapsibleSection title="Extracted Data" icon="📊">
        <MetadataThemes
          themes={displayMetadata.themes}
          onScoreClick={(theme) => showConfidenceDetails(theme)}
        />
        <MetadataEntities entities={displayMetadata.entities} />

        <AuditInfo
          created={displayMetadata.created}
          modified={displayMetadata.modified}
          modCount={displayMetadata.modificationCount}
        />
      </CollapsibleSection>
    </div>
  );
};

## Performance Optimization

```typescript
// packages/core/components/nodes/FlipBatchManager.ts
export class FlipBatchManager {
  private flipQueue: string[] = [];
  private animationFrame: number | null = null;

  batchFlip(nodeIds: string[]) {
    if (nodeIds.length > 10) {
      // Batch animations to prevent frame drops
      this.flipQueue.push(...nodeIds);
      this.processQueue();
    } else {
      // Direct flip for small batches
      nodeIds.forEach(id => this.flipNode(id));
    }
  }

  private processQueue() {
    if (this.animationFrame) return;

    this.animationFrame = requestAnimationFrame(() => {
      const batch = this.flipQueue.splice(0, 5); // Process 5 at a time
      batch.forEach(id => this.flipNode(id));

      if (this.flipQueue.length > 0) {
        this.animationFrame = null;
        this.processQueue();
      } else {
        this.animationFrame = null;
      }
    });
  }

  private flipNode(nodeId: string) {
    // Actual flip implementation
    const node = document.querySelector(`[data-node-id="${nodeId}"]`);
    node?.classList.toggle('flipped');
  }
}
```
