**Date: 16 March 2026**

This is why we’re building it.

The product turns a single reference image (palm tree, punk extra, cafe patron) into an editable, weighted-choice graph that can generate consistent, reusable variants.

Target workflow that the system is designed to enable (once preview and downstream conveniences are added):  
- Upload one reference -> bootstrap -> human-reviewed graph  
- Generate small clusters (5 characters max) or prop families  
- Export clean layers -> drag into scene -> use Photoshop’s Rotate Object tool -> Harmonize for floor contact, shadows, and lighting  
- Result: believable previs bricks that can feed into video models with depth maps

This is the daily driver for concept artists and previs leads who hate rebuilding consistency manually.

Strongest wedges (in order):  
1. Props/set dressing (palm-tree demo = instant “wow”)  
2. Crowds/extras (small clusters that feel like the same event)

Monetization starts with the structured graph tooling itself; generation credits and exports are convenient add-ons.

First public demo (30 seconds): one stock palm-tree photo -> editable graph -> multiple consistent variants.

This is the story that sells. Keep it alive.
