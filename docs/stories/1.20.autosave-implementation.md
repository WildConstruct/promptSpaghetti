# Story 1.20: autosave-implementation

## Story
**As a** user,
**I want** my work to be automatically saved at regular intervals,
**so that** I never lose more than a few seconds of work in case of unexpected issues.

## Acceptance Criteria
1) Autosave Mechanism
- A1. Implement debounced autosave triggered by graph changes (30-second delay)
- A2. Save triggers on: node add/delete, edge changes, property updates
- A3. Autosave respects the persistence layer from Story 1.19

2) Visual Feedback
- B1. Display save status indicator: "Saved", "Saving...", "Unsaved changes"
- B2. Show last saved timestamp (e.g., "Saved 2 minutes ago")
- B3. Indicator updates in real-time without blocking UI

3) Conflict Resolution
- C1. Detect concurrent edits from multiple tabs using storage events
- C2. Show conflict dialog when detected with options: "Keep mine", "Use theirs", "Merge"
- C3. Implement optimistic locking with version numbers

4) Performance
- D1. Autosave operations must complete in < 50ms for typical graphs
- D2. Large graphs (> 1000 nodes) use requestIdleCallback for saving
- D3. No UI blocking or stuttering during save operations

**Technical Considerations:**
- Use `useDebouncedCallback` from `use-debounce` package or implement custom
- Storage events API for cross-tab communication
- Version field in persisted state: increment on each save
- Consider using `BroadcastChannel` API for better cross-tab messaging (with fallback)

**Autosave Logic Pattern:**
```typescript
const useAutosave = (enabled: boolean = true) => {
  const [saveStatus, setSaveStatus] = useState<'saved' | 'saving' | 'unsaved'>('saved')
  const [lastSaved, setLastSaved] = useState<Date | null>(null)
  
  const debouncedSave = useDebouncedCallback(
    async () => {
      setSaveStatus('saving')
      try {
        await persistState()
        setSaveStatus('saved')
        setLastSaved(new Date())
      } catch (error) {
        setSaveStatus('unsaved')
        console.error('Autosave failed:', error)
      }
    },
    30000 // 30 seconds
  )
  
  useEffect(() => {
    if (!enabled) return
    
    const unsubscribe = graphStore.subscribe(
      (state) => state,
      () => {
        setSaveStatus('unsaved')
        debouncedSave()
      }
    )
    
    return unsubscribe
  }, [enabled, debouncedSave])
  
  return { saveStatus, lastSaved }
}
```

**Conflict Resolution Strategy:**
- Version-based optimistic locking
- Storage event contains: version, timestamp, tabId
- Conflict detection: local version < storage version
- Merge strategy: newer timestamp wins for non-conflicting changes

- Indicator placement: top-right corner, non-intrusive
- Colors: green (saved), yellow (saving), orange (unsaved)
- Animation: subtle fade transitions
- Accessibility: announce save status to screen readers
