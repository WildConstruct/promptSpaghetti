# Story 1.18: ci-preview-and-feature-flags

## Status
Implemented (CI wired; preview smoke test added; shim cleanup completed in Story 1.30)

## Story
**As a** maintainer,
**I want** CI/preview builds with correct gating,
**so that** previews work whether or not Supabase is configured.

## Acceptance Criteria
1) Preview behavior
- A1. Preview builds (Netlify/Vercel) run without Supabase envs; app functional with Supabase features hidden.
- A2. No runtime errors or logs spam due to missing envs.

2) Feature flags
- B1. Flag to disable Supabase features globally, regardless of envs.
- B2. Flags documented and readable from env (e.g., `NEXT_PUBLIC_FEATURE_SUPABASE=0`).

3) Manifest in CI
- C1. CI runs manifest generator and makes artifacts available to the app/build.
- C2. Build fails clearly if manifest step fails (unless explicitly skipped).

## Tasks / Subtasks
- Preview (A)
  - [x] Hide Supabase features when env/userId/helpers are missing (A1) — verified via `OpenGraphDialog` gating and tests in `packages/asset-browser/tests/`.
  - [x] Suppress noisy logs in preview (A2) — `packages/core/utils/supabaseClient.ts` warns only in local dev; no warnings in CI/prod when env is missing.
- Flags (B)
  - [x] Gating wired in UI/utils (B1) — `deriveEnableSupabaseProp()` used by UI; validated in tests (test shim during 1.18).
  - [x] Document flag and usage (B2) — `NEXT_PUBLIC_FEATURE_SUPABASE` documented in this story’s notes and prior stories.
- CI (C)
  - [x] Update CI to run manifest generator and expose output to build (C1–C2) — wired in `.github/workflows/ci.yml` ("Generate graph manifest" + artifact upload). Fails build unless `MANIFEST_OPTIONAL=true`.
- Preview smoke test
  - [x] Add preview smoke test (AC: 4) — `tests/performance/preview-smoke.spec.ts` ensures app boots without console errors.

## Dev Notes
- If manifest cannot be generated in preview, app should still run with empty server list.
- Keep CI logs informative when manifest or envs are missing.
 - Feature flag: `NEXT_PUBLIC_FEATURE_SUPABASE` (default `1`); set to `0` to disable globally.
 - Smoke test location: `tests/performance/preview-smoke.spec.ts`. Playwright baseURL: `http://localhost:3001` (matches Vite dev server), reuses existing server.

- Risks: Divergent preview vs prod behavior; mitigate with smoke tests.

  - `ts-jest` uses `<rootDir>/tsconfig.tests.json`.
