# Story 2.5: Asset Browser Integration & Dynamic Pairing

## Status
Draft - Ready for Review

## Story
**As a** prompt author working with the node graph and asset library,
**I want** drag-and-drop asset placement with intelligent metadata-based suggestions and node replacement capabilities,
**So that** I can quickly build coherent prompt graphs using contextually appropriate assets and maintain consistency across my virtual background scenes.

## Business Value
- **Demo Impact**: Visual drag-and-drop with smart suggestions creates powerful fundraising moments
- **Workflow Acceleration**: 10x faster graph building with metadata-driven asset pairing
- **Quality Improvement**: Automatic consistency checking prevents jarring combinations
- **User Delight**: "It knows what I need" feeling from intelligent suggestions

## Technical Implementation

### Asset Matching Service
```typescript
// packages/core/services/assetMatcher.ts
export class AssetMatcherService {
  private metadataCache: Map<string, NodeMetadata>;
  
  async findMatches(
    nodeMetadata: NodeMetadata,
    assets: Asset[],
    options: MatchOptions
  ): Promise<AssetMatch[]> {
    // Calculate relevance scores
    const matches = assets.map(asset => ({
      asset,
      score: this.calculateRelevance(nodeMetadata, asset.metadata),
      category: this.categorizeMatch(nodeMetadata, asset.metadata)
    }));
    
    // Sort by relevance
    return matches
      .filter(m => m.score >= options.threshold)
      .sort((a, b) => b.score - a.score)
      .slice(0, options.limit);
  }
  
  private calculateRelevance(
    nodeMetadata: NodeMetadata,
    assetMetadata: AssetMetadata
  ): number {
    let score = 0;
    
    // Exact matches: 40 points
    if (nodeMetadata.setting === assetMetadata.setting) score += 40;
    
    // Mood compatibility: 30 points
    if (this.moodsCompatible(nodeMetadata.mood, assetMetadata.mood)) {
      score += 30;
    }
    
    // Prop overlap: up to 30 points
    const propOverlap = this.calculatePropOverlap(
      nodeMetadata.props,
      assetMetadata.props
    );
    score += propOverlap * 30;
    
    return Math.min(score, 100);
  }
}
```

### Drag-and-Drop Handler
```typescript
// packages/core/components/AssetBrowser/DragDropHandler.tsx
export function useDragDrop() {
  const handleDrop = useCallback((event: DragEvent, targetNode?: Node) => {
    const asset = JSON.parse(event.dataTransfer.getData('asset'));
    
    if (targetNode) {
      // Show replacement menu
      showReplacementMenu({
        asset,
        target: targetNode,
        position: { x: event.clientX, y: event.clientY },
        onReplace: () => replaceNode(targetNode, asset),
        onMerge: () => mergeIntoNode(targetNode, asset),
        onVariant: () => createVariant(targetNode, asset)
      });
    } else {
      // Create new node group
      const position = screenToCanvas({ x: event.clientX, y: event.clientY });
      createNodeFromAsset(asset, position);
    }
  }, []);
  
  return { handleDrop };
}
```
