# Story 1.9: open-dialog-server-and-local

## Status
Complete

## Story
**As a** user,
**I want** an Open dialog with Server and Local tabs,
**so that** I can load graphs either from demo list or my local files.

## Acceptance Criteria
1) Dialog and navigation
- A1. `OpenGraphDialog` shows tabs: Server (manifest) and Local (file picker).
- A2. Keyboard navigation is supported (Tab, Arrow keys within list, Enter to open).
- A3. Loading indicators are shown while fetching the manifest.

2) Server tab
- B1. Server list renders entries from manifest with title and updatedAt.
- B2. Selecting an item downloads and opens the `.psg` file via codec; errors are surfaced.
- B3. Empty/Error state appears for missing or empty manifest with retry.

3) Local tab
- C1. Local picker accepts `.psg` and legacy `.graph.json`.
- C2. Legacy files are migrated in-memory using `fromLegacyGraph`.
- C3. Parsing errors display friendly messages; user can retry.
