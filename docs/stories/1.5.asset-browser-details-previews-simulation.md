# Story 1.5: Asset Browser – Details Drawer Previews & Simulation Hooks (Scaffold)

## Status

Complete

## Story

**As a** graph editor user,
**I want** a Details Drawer that shows sample outputs and a branch visualization on demand,
**so that** I can evaluate presets quickly before inserting them into my graph.

## Acceptance Criteria

1. Details Drawer displays two preview sections: Sample Outputs (Tier-2 placeholder) and Branch Map (Tier-4 placeholder).
2. "Simulate" button exists and triggers an async call to a `PreviewService.simulate()` stub that returns three sample strings (seed 0–2) for now.
3. "Branch Viz" toggle renders a placeholder SVG via `BranchVisualization` component (reads from `PreviewService.branchMap()` stub).
4. UI indicates async loading state and error states for both preview sections; non-blocking to the rest of the browser.
5. Web Worker scaffolding exists (`preview.worker.ts`, `thumbnail.worker.ts`), even if logic is stubbed; communication uses Comlink.
6. The preview cache respects content-hash keys; cache misses trigger a stubbed generation path; hits show cached placeholders.
7. All features are keyboard-accessible and screen-reader labeled (buttons, toggles, status text). Enter activates Simulate, Space toggles Branch Viz.
8. Unit tests cover simulate trigger, loading/error states, and keyboard activation paths.
