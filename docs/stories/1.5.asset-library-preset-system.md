# Story 1.5: Asset Library & Preset System

## Status
Approved

## Story
**As a** creative professional,  
**I want** to drag presets onto nodes and immediately edit them inline,  
**so that** I can customize presets without interrupting my flow.

## Acceptance Criteria
1. Drag preset onto node replaces content
2. Dropped presets enter edit mode automatically
3. Preset preview appears during hover
4. Inline editing of preset values post-drop
5. Visual indication of modified presets (removed save-back for MVP)

## Dev Notes
### Architecture Context
- Library should be extensible for future preset marketplace
- Must work seamlessly with inline editing system
- Performance critical for large preset libraries
- Consider lazy loading for preset content

### Technical Implementation Details
```typescript
interface Preset {
  id: string;
  name: string;
  category: string;
  tags: string[];
  nodeType: NodeType;
  value: any;
  metadata: {
    author?: string;
    created: Date;
    modified?: Date;
    usage: number;
  };
}

interface PresetLibrary {
  categories: Category[];
  presets: Preset[];
  
  searchPresets(query: string): Preset[];
  getCompatiblePresets(nodeType: NodeType): Preset[];
  savePreset(preset: Preset): void;
}
```

### Drag-Drop Architecture
- Use React DnD for complex drag interactions
- Implement custom drag preview
- Handle multi-node selection drops
- Support keyboard alternatives

### Medieval Demo Presets
Categories needed:
- Character Occupations (merchant, knight, peasant)
- Character States (weary, noble, wounded)
- Clothing/Appearance (tattered robes, armor, tunics)
- Items/Props (scrolls, swords, potions)
- Settings (marketplace, castle, tavern)

### Performance Strategy
- Virtual scrolling for large libraries
- Lazy load preset content
- Index presets for fast search
- Cache compatibility checks

### Rollback Procedures
1. **Feature Flag Rollback**: Asset library behind flag `asset-library-v2`
2. **Data Rollback**: Preset data stored separately, can disable without data loss
3. **UI Fallback**: Show basic node palette if library fails
4. **Emergency Procedure**:
   - Disable drag-drop functionality
   - Hide library panel via feature flag
   - Maintain manual node creation
5. **Preset Recovery**: All presets backed up before modifications
