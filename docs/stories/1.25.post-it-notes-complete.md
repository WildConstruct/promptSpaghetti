- ✅ **C2: Visual Connection**

  - Drag away to detach
  - Visual feedback via attachment edge

- ✅ **C4: Maintain Relative Position**
  - Stores attachment offset

  - Attachment persists across sessions

#### Persistence
- ✅ **Local Storage Integration**

  text: string;

### Usage

1. **Create Note**: Right-click on canvas → "Add Post-it Note"
2. **Edit Note**: Double-click to enter edit mode (supports Markdown)
3. **Attach to Node**: 
   - Method 1: Right-click node → "Attach Note"
   - Method 2: Drag note near a node
4. **Detach**: Drag attached note away from node
5. **Resize**: Drag bottom-right corner
6. **Collapse**: Click arrow button to minimize
7. **Delete**: Click × button
