Draft - Ready for Review

**I want** basic drag-and-drop asset placement with metadata-based suggestions and simple node replacement,
**So that** I can quickly build coherent prompt graphs during fundraising demos while maintaining the "it knows what I need" magic moment.

- **MVP Focus**: Core features only for fundraising success in 1 week

- **SAG-Forward**: Consent validation demonstrates ethics commitment

## Acceptance Criteria

### 1. Core Drag-and-Drop (Priority: P0)
- Restore basic drag-and-drop from asset browser to canvas
- Support for PSG fragments and PSGLib presets only (not individual nodes yet)
- Simple visual feedback:
  - Ghost preview during drag
  - Green highlight for valid drop zones
  - Red overlay for invalid areas
- Drop behaviors (simplified):
  - Drop on empty canvas: Create nodes at position
  - Drop on node: Show simple replacement dialog
  - No auto-connect in MVP (manual connection only)

### 2. Simple Node Replacement (Priority: P0)
- When dropping asset on existing node:
  - Modal dialog with two options:
    - "Replace Node" - Swap and try to preserve connections
    - "Cancel" - Abort operation
- Basic connection preservation:
  - Keep connections if types match
  - Show warning if connections will be lost
  - No auto-adaptation in MVP
- Undo support for replacement (single-level)

### 3. Basic Metadata Matching (Priority: P0)
- Leverage Story 2.3a's metadata extraction:
  - Use existing tags: theme, mood, setting
  - Simple relevance scoring (high/medium/low)
  - No complex calculations in MVP
- Asset browser shows match indicators:
  - ✓ High match (>70%)
  - ~ Medium match (40-70%)
  - (no indicator for low match)
- Filter toggle: "Show Matches Only" checkbox

### 4. Essential Suggestions Panel (Priority: P0)
- "Suggested Assets" sidebar (collapsible):
  - Shows top 3 relevant assets
  - Updates when node selected
  - Simple list view (no categories)
- Basic suggestion logic:
  ```javascript
  // MVP: Simple keyword matching
  if (node.metadata.setting === asset.metadata.setting) {
    relevance = "high";
  } else if (hasCommonTags(node, asset)) {
    relevance = "medium";
  }
  ```
- Click suggestion to start drag operation

### 5. WeightedChoice Quick Add (Priority: P1)
- Special behavior for WeightedChoice only:
  - Dropping compatible asset adds as new choice
  - Default weight of 5 (middle value)
  - Shows toast: "Added as choice option"
- No batch operations or reordering in MVP
- Manual weight adjustment via inspector

### 6. Invalid Drop Handling (Priority: P0)
- Clear error messages with specific recovery actions:
  - Type incompatibility: "Can't replace TextBlock with WeightedChoice. Use empty canvas or convert TextBlock to WeightedChoice first."
  - Connection conflicts: "This would break 3 connections. Disconnect downstream nodes or use 'Replace All' (coming in 2.5b)."
  - Invalid position: "Can't drop here - too close to edge. Move 50px inward or use grid snap (G key)."
- Toast notifications with immediate actions:
  - "Try dropping on empty canvas instead → Click here to auto-scroll to empty area"
  - "This asset needs a WeightedChoice node → Press W to create one"
  - "Incompatible node types → View compatibility matrix (? key)"
- Visual feedback persists for 2 seconds with progress bar
- Error recovery suggestions stored in help system

### 7. Offline Fallback (Priority: P1)
- When LLM unavailable (from Story 2.3a):
  - Use static keyword matching for suggestions
  - Match based on node type compatibility
  - Show indicator: "Basic matching (offline)"
- Pre-computed compatibility matrix:

### Minimal Asset Matcher Service
```typescript
// packages/core/services/assetMatcher.ts
export class AssetMatcherService {
  findMatches(nodeMetadata: NodeMetadata, assets: Asset[]): AssetMatch[] {
    return assets
      .map(asset => ({
        asset,
        score: this.calculateSimpleScore(nodeMetadata, asset.metadata)
      }))
      .filter(m => m.score > 0)
      .sort((a, b) => b.score - a.score)
      .slice(0, 3); // Top 3 only for MVP
  }
  
  private calculateSimpleScore(node: NodeMetadata, asset: AssetMetadata): number {
    let score = 0;
    if (node.setting === asset.setting) score += 50;
    if (node.mood === asset.mood) score += 30;
    if (node.theme === asset.theme) score += 20;
    return score;
  }
}
```

### Drag Operation Performance Monitor
```typescript
// packages/core/services/performanceMonitor.ts
export class DragPerformanceMonitor {
  private metrics: Map<string, number[]> = new Map();
  
  startDragOperation(dragId: string): void {
    this.metrics.set(dragId, [performance.now()]);
  }
  
  recordDragEvent(dragId: string, event: 'hover' | 'validate' | 'drop'): void {
    const times = this.metrics.get(dragId) || [];
    times.push(performance.now());
    
    // Alert if exceeding targets
    const duration = times[times.length - 1] - times[0];
    if (duration > 100) {
      console.warn(`Drag operation ${event} exceeded 100ms target: ${duration}ms`);
      this.reportToAnalytics(dragId, event, duration);
    }
  }
  
  reportToAnalytics(dragId: string, event: string, duration: number): void {
    // Send to monitoring dashboard
    if (window.analyticsReporter) {
      window.analyticsReporter.track('drag_performance', {
        dragId,
        event,
        duration,
        exceeded: duration > 100
      });
    }
  }
}
```

            key={action.label}

          </button>

    </div>
  );
};
