### Polish Checklist
1. **Visual Polish**:
   - Consistent spacing (8px grid)
   - Harmonious color palette
   - Readable typography
   - Accessible contrast ratios

2. **Interaction Polish**:
   - Predictable behaviors
   - Clear affordances
   - Helpful constraints
   - Forgiving interactions

3. **Performance Polish**:
   - No jank during animations
   - Instant feedback (<16ms)
   - Smooth transitions
   - Progressive enhancement

### Medieval Demo Script
1. Start with empty canvas
2. Paste: "A weary merchant in tattered robes"
3. Show instant node generation
4. Click to edit "merchant" → "knight"
5. Drag "Fantasy Occupations" preset
6. Show live preview updates
7. Generate 20 variations
8. Time: <30 seconds total

### Hidden Details
- Konami code enables "weird mode"
- Long-press shows debug info
- Triple-click for expert mode
- Shake to shuffle presets
- Hold shift for precision mode

### Rollback Procedures
1. **Feature Flag Rollback**: Each polish feature individually flagged
2. **Animation Rollback**: CSS class to disable all animations
3. **Performance Fallback**: Reduce animation complexity on slow devices
4. **Emergency Procedure**:
   - "Safe mode" disables all polish features
   - Focus on core functionality only
   - Performance > Polish principle
5. **Demo Backup**: Static demo video if live demo fails
