## Status
Implemented

## Story

**I want** the core package to build cleanly with proper exports and type definitions,  
**so that** I can import utilities without shims and maintain clean dependency boundaries

## Acceptance Criteria
1. Build succeeds: `pnpm -w --filter @promptscape/core build` produces dist/esm, dist/cjs, and dist/types without errors

4. Asset Browser green: Asset Browser typecheck and tests pass after removing the Jest mapper and TS shim for @promptscape/core/utils
5. Public surface trimmed: packages/core/index.ts exports only stable modules with no unresolved/missing module references
6. CI validation: Core build passes in CI pipeline without errors or warnings
7. Documentation updated: packages/core/README.md includes clear import instructions for subpath exports

### Build Configuration Notes
- Current issue: TypeScript declaration generation tries to overwrite input files
- Root cause: Misaligned rootDir/outDir settings across config files
- Solution: Ensure all configs output to dist/ subdirectories only

### Downstream Impact
- packages/asset-browser currently uses Jest moduleNameMapper shim
- Other packages may have similar workarounds
- After fix, all packages should import directly without configuration
