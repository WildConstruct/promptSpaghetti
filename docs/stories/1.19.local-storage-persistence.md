# Story 1.19: local-storage-persistence

## Status
Done

## Story
**As a** user,
**I want** my graph state to persist in browser storage,
**so that** I don't lose my work when I refresh the page or close the browser.

## Acceptance Criteria
1) Persistence Layer
- A1. Implement Zustand persist middleware for graphStore with localStorage adapter
- A2. Store includes: nodes, edges, viewport position, and last modified timestamp
- A3. Use versioned schema (v1) to enable future migrations

2) Storage Management
- B1. Implement storage key namespacing: `promptgraph:state:v1`
- B2. Add compression for graphs > 100KB using LZ-string or similar
- B3. Handle localStorage quota errors gracefully with user notification

3) Feature Gating
- C1. Respect feature flag `NEXT_PUBLIC_FEATURE_AUTOSAVE` (default: true)
- C2. When disabled, no localStorage operations occur
- C3. Existing manual save/load functionality unaffected

4) Data Integrity
- D1. Validate stored data on load using Zod schemas
- D2. Provide fallback to empty state if validation fails
- D3. Log validation errors for debugging (dev mode only)

**Technical Considerations:**
- Use `zustand/middleware` persist with custom storage adapter
- Storage format: JSON with optional compression for large graphs
- Key naming: `promptgraph:state:v1` for main state, consider separate keys for drafts
- Compression library suggestion: `lz-string` (small, fast, localStorage-safe)
- Maximum localStorage size: ~5-10MB depending on browser
- Consider IndexedDB for future if size becomes issue

**Integration Points:**
- Must not interfere with existing SaveGraphDialog functionality
- Should work alongside Supabase saves (Stories 1.11-1.13)
- Respect feature flags from Story 1.18 pattern

**Example Implementation Pattern:**
```typescript
import { persist, createJSONStorage } from 'zustand/middleware'
import { compress, decompress } from 'lz-string'

const persistConfig = {
  name: 'promptgraph:state:v1',
  storage: createJSONStorage(() => ({
    getItem: (name) => {
      const str = localStorage.getItem(name)
      if (!str) return null
      const { state, version } = JSON.parse(str)
      if (version !== 1) return null
      return decompress(state)
    },
    setItem: (name, value) => {
      const compressed = compress(value)
      localStorage.setItem(name, JSON.stringify({ 
        state: compressed, 
        version: 1,
        timestamp: Date.now()
      }))
    },
    removeItem: (name) => localStorage.removeItem(name)
  })),
  partialize: (state) => ({
    nodes: state.nodes,
    edges: state.edges,
    viewport: state.viewport
  })
}
```

1. Update GraphEditor to use persisted store:
```typescript
import { createPersistedGraphStore } from './graphStorePersisted';
// Instead of: import { useGraphStore } from './graphStore';
```

2. Wrap app with StorageErrorBoundary:
```typescript
import { StorageErrorBoundary } from '@promptscape/core/components/StorageErrorBoundary';

<StorageErrorBoundary>
  <App />
</StorageErrorBoundary>
```
