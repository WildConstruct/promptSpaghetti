# Story 1.8: manifest-generator-and-demo-assets

## Status
Complete

## Story
**As a** beta user,
**I want** a Server tab listing demo graphs,
**so that** I can quickly explore sample `.psg` graphs without local files.

## Acceptance Criteria
1) Manifest generation
- A1. A script generates `public/graphs/manifest.json` by scanning `public/graphs/*.psg`.
- A2. Each entry includes: `filename`, `title` (from file or derived), optional `tags`, and `updatedAt` (file mtime).

2) Build integration
- B1. The manifest generator runs automatically as a prebuild step locally and in CI.
- B2. CI/preview builds succeed even with zero `.psg` files; an empty manifest is valid.

3) App consumption and fallback
- C1. The app loads `public/graphs/manifest.json` and renders the list in the Server tab.
- C2. If `manifest.json` is missing/404 or empty, show an Empty State with retry and a doc link.

4) Demo assets
- D1. Provide 3–5 demo `.psg` graphs under `public/graphs/` that pass codec validation.
