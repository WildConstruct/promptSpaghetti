# Story 2.3a: Metadata Extraction & Basic Intelligence (MVP Priority)

## Status
Draft - Ready for Review

## Story
**As a** prompt author working with multiple segments and assets,
**I want** automatic metadata extraction that runs invisibly in the background,
**so that** my content is intelligently tagged for search and organization without any manual effort.

## Business Value
- **Invisible Intelligence**: Makes app feel smart without user awareness
- **Demo Enhancement**: Shows sophisticated analysis during fundraising
- **Foundation Layer**: Enables future asset matching and continuity
- **Quick Implementation**: 3-4 days for core extraction

## Acceptance Criteria

### 1. Automatic Background Metadata Extraction
- On segment save/edit (debounced 1 second after typing stops)
- Extracts core metadata silently:
  ```json
  {
    "subject": "sports car",
    "action": "drifting",
    "location": "desert",
    "mood": "intense",
    "intensity": 8,
    "tags": ["vehicle", "action", "outdoor"]
  }
  ```
- No UI indication during extraction (fully transparent)
- Metadata stored on segment object but hidden from view
- Accessible only via inspector "Debug" tab (developer mode)
- Zero user intervention required

### 2. Smart Asset Discovery (Basic)
- Asset browser shows "Smart Match" toggle
- When enabled, filters assets by current segment metadata
- Simple tag matching algorithm:
  - Exact tag matches show first
  - Partial matches show second
  - No match items hidden
- Match count badge shows "12 matches found"
- Instant filtering as user navigates segments
- **Offline Mode Enhancement**:
  - Pre-cache top 5 matches for common categories
  - Cache key scenarios: "urban chaos", "desert scene", "crowd panic"
  - localStorage stores: `{category: string, topMatches: Asset[]}`
  - Offline returns cached matches with "Cached" badge
  - Demo reliability: 100% even without network
  - Cache refresh on successful online match

### 3. Metadata Performance & Efficiency
- Extraction completes in <500ms per segment
- Cached for identical text (1 hour TTL)
- Batched for multiple edits (max 5 segments/batch)
- Non-blocking - UI remains responsive
- Graceful degradation if LLM unavailable
- Maximum 100 bytes metadata per segment

### 4. Basic Search Enhancement
- Search box accepts natural language
- Converts to tag-based filtering:
  - "urban scenes" → location:urban
  - "intense action" → mood:intense + action:*
- Falls back to text search if no metadata
- Results sorted by relevance score
- Search completes in <200ms

### 5. Privacy & Consent Foundation
- Metadata includes extraction source:
  ```json
  {
    "extracted_by": "deepseek/deepseek-r1:free",
    "extraction_date": "2025-01-25T10:00:00Z",
    "consent_flag": true
  }
  ```
- No PII extracted or stored
- Metadata excluded from exports by default
- User can view/delete metadata via settings

### 6. Developer Mode Visibility
- Toggle in settings: "Show Metadata (Dev)"
- When enabled, inspector shows metadata tab
- Raw JSON view of extracted data
- Extraction log with timing info
- Manual re-extraction button for testing

## Technical Implementation

### Lightweight Metadata Service
```typescript
// MetadataExtractor.ts - Simplified for MVP
export class MetadataExtractor {
  private cache = new Map<string, Metadata>();
  
  async extractInBackground(segment: Segment): Promise<void> {
    // Fire and forget - no UI blocking
    this.extract(segment.text).then(metadata => {
      segment.metadata = metadata;
      this.updateSearchIndex(segment.id, metadata);
    }).catch(error => {
      // Silent failure - no user notification
      console.debug('Metadata extraction failed:', error);
    });
  }
  
  private async extract(text: string): Promise<Metadata> {
    const cached = this.cache.get(text);
    if (cached) return cached;
    
    try {
      const metadata = await llmService.extractMetadata({
        text,
        maxTokens: 100, // Keep it tiny
        model: 'anthropic/claude-haiku' // Good for classification
      });
      
      this.cache.set(text, metadata);
      return metadata;
    } catch {
      // Return minimal metadata on failure
      return { tags: [], subject: 'unknown' };
    }
  }
}
```

### Debounced Background Processing
```typescript
// In segment editor
const extractMetadataDebounced = debounce((segment) => {
  metadataExtractor.extractInBackground(segment);
}, 1000);

// On text change
const handleTextChange = (text: string) => {
  segment.text = text;
  extractMetadataDebounced(segment); // Non-blocking
};
```

- **Risk**: Extraction failures visible to user
  - **Mitigation**: Silent failures, cached demo data
- **Risk**: Performance impact
  - **Mitigation**: Debouncing, background processing, caching
- **Risk**: Irrelevant metadata
  - **Mitigation**: Simple schema, limited extraction scope
