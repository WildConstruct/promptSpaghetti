# Story 6.3: Ctrl-Click Node Palette Access

## Status
Draft

## Story
**As a** user of the prompt-spaghetti application,
**I want** a quick node creation system activated by Ctrl+clicking on the canvas,
**so that** I can rapidly add nodes at precise locations without dragging from the sidebar palette, improving my workflow efficiency.

## Acceptance Criteria

1. **Canvas Event Handling**: Application detects Ctrl+click (Windows) or Cmd+click (Mac) events on empty canvas areas, distinguishing from clicks on existing nodes/edges, and stores click coordinates for precise node placement

2. **Context-Aware Floating Palette**: System displays a compact floating node palette at the click location with context-aware filtering, recently used nodes prioritization, and auto-positioning to stay within screen boundaries

3. **Precise Node Placement**: Selected nodes are created exactly at the clicked coordinates with proper offset calculations, zoom level adjustments, and grid snapping integration when enabled

4. **User Experience Features**: System includes ghost node preview during selection, keyboard navigation for the floating palette, smooth show/hide animations, and cancellation on Escape key or click outside

5. **User Education & Onboarding**: Application provides tooltip-based feature introduction after user performs multiple drag operations, keyboard shortcuts help integration, and optional animated tutorial for first-time users

6. **Accessibility & Performance**: Feature includes keyboard alternatives for all interactions, proper ARIA labels, color contrast compliance, and optimized rendering performance for the floating palette
