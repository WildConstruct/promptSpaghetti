# Story 1.3: Visual Node Editor with React Flow

## Status
Approved

## Story
**As a** filmmaker,  
**I want** to edit my prompts directly on the visual canvas,  
**so that** I can see relationships while making changes.

## Acceptance Criteria
1. Custom React Flow nodes with inline editing UI
2. Click node to enter edit mode
3. Visual feedback during editing (glow, expanded size)
4. Live preview updates as you type
5. Weighted choice nodes show interactive sliders
6. Connection validation prevents invalid links
7. Pan/zoom works even during editing

## Dev Notes
### Architecture Context
- Builds on React Flow's custom node system
- Must maintain React Flow's performance optimizations
- Integrates with Story 1.1's EditableNode interface
- Critical for achieving the "Teenage Engineering" feel

### Technical Implementation Details
```typescript
const CustomNodeComponent = ({ data, selected }: NodeProps) => {
  const { isEditing, value, editBuffer } = data;
  
  return (
    <div className={`node ${isEditing ? 'editing' : ''}`}>
      {isEditing ? (
        <InlineEditor value={editBuffer} onChange={updateBuffer} />
      ) : (
        <NodeDisplay value={value} />
      )}
      <Handle type="target" position={Position.Left} />
      <Handle type="source" position={Position.Right} />
    </div>
  );
};
```

### React Flow Integration
- Use nodeTypes prop to register custom components
- Leverage React Flow's state management
- Hook into onNodesChange for updates
- Use React Flow's viewport controls

### Styling Strategy
```css
.node.editing {
  box-shadow: 0 0 20px rgba(100, 200, 255, 0.6);
  transform: scale(1.05);
  transition: all 0.2s ease;
}
```

### Performance Considerations
- Use React.memo for node components
- Virtualize nodes outside viewport
- Debounce expensive operations
- Profile with React DevTools

### Rollback Procedures
1. **Feature Flag Rollback**: Inline editing behind flag `inline-editor-v2`
2. **Component Rollback**: Swap to legacy sidebar editor component
3. **State Rollback**: Clear any corrupted edit states from localStorage
4. **Emergency Procedure**:
   - Toggle feature flag to show legacy editor
   - Clear browser cache if UI corruption
   - Preserve user's graph data throughout
5. **Gradual Rollout**: Start with 10% users, monitor for issues
