# Story 1.25: post-it-notes-comments

## Status
Done

## Story
**As a** graph designer,
**I want** to add post-it notes and comments to my graphs,
**so that** I can document my thinking, leave reminders, and communicate intent to collaborators.

## Acceptance Criteria
1) Note Creation
- A1. Right-click on canvas shows "Add Note" option
- A2. Click-drag to create note with size
- A3. Double-click to edit note content
- A4. Support markdown formatting in notes

2) Note Features
- B1. 6 color options (yellow, blue, green, pink, orange, purple)
- B2. Resize handles on corners and edges
- B3. Delete button (X) on hover
- B4. Collapse to title bar to reduce clutter
- B5. Z-index management (bring to front/send to back)

3) Note Attachment
- C1. Drag note onto node to attach (visual link indicator)
- C2. Attached notes move with their parent node
- C3. Detach by dragging away from node
- C4. Delete node warns about attached notes

4) Persistence
- D1. Notes save with graph data
- D2. Note positions relative to viewport
- D3. Export includes notes in separate layer
- D4. Import preserves note relationships

**PostItNote Component Structure:**
```typescript
interface PostItNote {
  id: string
  content: string
  position: XYPosition
  size: { width: number; height: number }
  color: NoteColor
  collapsed: boolean
  attachedTo?: string // nodeId
  zIndex: number
  createdAt: number
  updatedAt: number
}

type NoteColor = 'yellow' | 'blue' | 'green' | 'pink' | 'orange' | 'purple'

const PostItNoteComponent: React.FC<PostItNoteProps> = ({
  note,
  onUpdate,
  onDelete,
  isSelected
}) => {
  const [isEditing, setIsEditing] = useState(false)
  const [content, setContent] = useState(note.content)
  
  return (
    <div
      className={`post-it-note ${note.color}`}
      style={{
        transform: `translate(${note.position.x}px, ${note.position.y}px)`,
        width: note.size.width,
        height: note.collapsed ? 30 : note.size.height,
        zIndex: note.zIndex
      }}
    >
      <div className="note-header">
        <div className="note-title">
          {note.content.split('\n')[0] || 'Note'}
        </div>
        <div className="note-controls">
          <button onClick={() => onCollapse()}>
            {note.collapsed ? '▼' : '▲'}
          </button>
          <button onClick={() => onDelete(note.id)}>✕</button>
        </div>
      </div>
      
      {!note.collapsed && (
        <div className="note-content">
          {isEditing ? (
            <textarea
              value={content}
              onChange={(e) => setContent(e.target.value)}
              onBlur={() => handleSave()}
              autoFocus
            />
          ) : (
            <ReactMarkdown>{content}</ReactMarkdown>
          )}
        </div>
      )}
      
      {!note.collapsed && <ResizeHandles onResize={handleResize} />}
    </div>
  )
}
```

**Interaction Patterns:**
- Use React Flow's `useOnSelectionChange` for multi-select
- Leverage `onPaneClick` for canvas interactions
- Custom drag handler for attachment detection
- Keyboard shortcuts: Cmd+Shift+N (new note), Delete (remove selected)

**Performance Considerations:**
- Lazy render notes outside viewport
- Debounce note content updates
- Use CSS transforms for positioning (GPU accelerated)
- Virtualize note list in sidebar if > 50 notes
