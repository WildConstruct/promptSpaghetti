# Story 1.15: error-empty-states-and-fallbacks

## Status
Implemented

## Story
**As a** user,
**I want** clear empty and error states,
**so that** I understand what went wrong and what I can do next.

## Acceptance Criteria
1) Manifest
- A1. Missing/404 `manifest.json` shows an Empty State with retry and doc link.
- A2. Empty manifest shows Empty State with guidance.

2) Supabase gating
- B1. Supabase not configured (or no userId) hides the tab and shows a tooltip/notice in-save flows.
- B2. When hidden, no Supabase calls are attempted.

3) Network errors
- C1. Fetch/list/get/put errors render user-friendly messages and provide retry.
- C2. Retries backoff minimally to avoid hammering.

4) Parsing errors
- D1. Invalid `.psg` shows validation feedback; lists top-level error(s).
- D2. Legacy migration errors offer guidance to try local save after fixes.
