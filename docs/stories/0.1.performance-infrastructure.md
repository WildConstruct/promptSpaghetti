# Story 0.1: performance-infrastructure

## Status
Ready for Development

## Story
**As a** system architect,
**I want** a robust performance infrastructure for graph operations,
**So that** the application can handle real-world graphs (200-500+ nodes) without degradation.

## Acceptance Criteria
1) Caching Layer
- A1. Implement multi-level LRU cache for path calculations
- A2. Achieve >85% cache hit ratio for repeated operations
- A3. Cache invalidation on node/edge changes
- A4. Persistent cache for session continuity
- A5. Cache size limits with automatic eviction

2) Background Processing
- B1. Web Worker pool for computations >10ms
- B2. Non-blocking UI during path calculations
- B3. Automatic work distribution across workers
- B4. Graceful fallback if workers unavailable
- B5. Progress indication for long operations

3) Performance Targets
- C1. Support 1000+ nodes with <200ms initial render
- C2. Maintain 60fps during drag/pan/zoom operations
- C3. Edge routing calculations <50ms for 500+ edges
- C4. Memory usage <200MB for large graphs
- C5. No UI freezes during any operation

4) Monitoring & Metrics
- D1. Performance dashboard with real-time metrics
- D2. Render time tracking per operation
- D3. Memory usage monitoring and alerts
- D4. Cache efficiency statistics
- D5. Worker utilization metrics

## Dev Notes
**Architecture Overview:**
```typescript
// Core Performance Infrastructure
interface PerformanceInfrastructure {
  cache: MultiLevelCache;
  workers: WorkerPool;
  monitor: PerformanceMonitor;
  optimizer: RenderOptimizer;
}

// Multi-level Cache
class MultiLevelCache {
  private l1: LRUCache<string, any>; // Hot - Memory
  private l2: Map<string, any>;      // Warm - Session
  private l3: IndexedDB;              // Cold - Persistent
  
  async get(key: string): Promise<any> {
    return this.l1.get(key) || 
           this.l2.get(key) || 
           await this.l3.get(key);
  }
}

// Worker Pool Manager
class WorkerPool {
  private workers: Worker[];
  private queue: PriorityQueue<WorkItem>;
  private maxWorkers = navigator.hardwareConcurrency || 4;
  
  async execute<T>(task: WorkerTask): Promise<T> {
    const worker = await this.getAvailableWorker();
    return this.runTask(worker, task);
  }
}

// Performance Monitor
class PerformanceMonitor {
  private metrics: Map<string, PerformanceMetric>;
  private thresholds: Map<string, number>;
  
  measure(operation: string, fn: () => void): void {
    const start = performance.now();
    fn();
    const duration = performance.now() - start;
    this.record(operation, duration);
  }
}
```

```typescript
// Cached edge routing
const getCachedPath = async (edge: Edge) => {
  const cacheKey = `path:${edge.source}:${edge.target}:${edge.id}`;
  
  // Try cache first
  const cached = await cache.get(cacheKey);
  if (cached) return cached;
  
  // Calculate in worker if complex
  if (edge.controlPoints?.length > 2) {
    const path = await workerPool.execute({
      type: 'CALCULATE_PATH',
      data: edge
    });
    await cache.set(cacheKey, path);
    return path;
  }
  
  // Simple calculation inline
  const path = calculateSimplePath(edge);
  await cache.set(cacheKey, path);
  return path;
};

// Viewport culling for edges
const getVisibleEdges = (edges: Edge[], viewport: Viewport) => {
  return edges.filter(edge => {
    const bounds = getEdgeBounds(edge);
    return viewport.intersects(bounds);
  });
};
```
