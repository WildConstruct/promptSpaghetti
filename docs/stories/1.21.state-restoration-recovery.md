# Story 1.21: state-restoration-recovery

## Status
Done

## Story
**As a** user,
**I want** my graph state to be automatically restored when I return to the application,
**so that** I can continue exactly where I left off without manual intervention.

## Acceptance Criteria
1) Automatic Restoration
- A1. Load persisted state on application mount automatically
- A2. Restore: nodes, edges, viewport position, and selection state
- A3. Show loading indicator during restoration process

2) Recovery UI
- B1. Display recovery dialog when corrupted state detected
- B2. Options: "Attempt Recovery", "Start Fresh", "Load from File"
- B3. Show details of what can be recovered (e.g., "50 of 52 nodes recoverable")

3) Reset Functionality
- C1. Provide "Reset to Default" button in settings/menu
- C2. Confirm dialog before clearing: "This will delete your unsaved work"
- C3. Clear localStorage and reset to empty graph state

4) State Information
- D1. Display "Last modified" timestamp in UI
- D2. Show storage usage (e.g., "Using 1.2 MB of 5 MB available")
- D3. Add "Export Backup" option before reset operations

### Integration Instructions
To enable state restoration in the application:

1. Import restoration utilities in App.tsx:
```typescript
import { restoreState } from '@promptscape/core/utils/stateRestoration';
import { RestorationLoader, RestorationToast } from '@promptscape/core/components/indicators/RestorationLoader';
import { StateRecoveryDialog } from '@promptscape/core/components/recovery/StateRecoveryDialog';
```

2. Add restoration logic on app mount:
```typescript
useEffect(() => {
  const restore = async () => {
    setLoading(true);
    const result = await restoreState();
    
    if (result.success) {
      // Apply restored state to store
      graphStore.setState(result.state);
      showToast('success', 'Work restored');
    } else if (result.recovered) {
      // Show recovery dialog
      setShowRecovery(true);
      setRecoveryReport(result.report);
    }
    
    setLoading(false);
  };
  
  restore();
}, []);
```
