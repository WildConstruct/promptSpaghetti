# Story 1.24: protected-features-anonymous-mode

## Status
Ready for Review

## Story
**As a** product owner,
**I want** a seamless experience for both authenticated and anonymous users,
**so that** users can try the app without signing up while being encouraged to create accounts for advanced features.

## Acceptance Criteria
1) Feature Gating
- A1. Cloud save/load features visible only when authenticated
- A2. Local save/load always available to all users
- A3. Export/import functionality available to all users
- A4. Feature availability respects both auth state and feature flags

2) Anonymous Experience
- B1. Full graph editor functionality without authentication
- B2. Local storage persistence works for anonymous users
- B3. No auth prompts during core workflow
- B4. Clear indication of what features require authentication

3) Upgrade Prompts
- C1. Contextual "Sign in to enable" messages on gated features
- C2. Non-intrusive upgrade prompts after significant work (e.g., 10+ nodes)
- C3. Benefits clearly explained: "Save to cloud", "Access anywhere", "Never lose work"
- C4. One-click transition from anonymous to authenticated with work preserved

4) Feature Flag Control
- D1. `NEXT_PUBLIC_FEATURE_AUTH` flag to enable/disable auth entirely
- D2. `NEXT_PUBLIC_REQUIRE_AUTH` flag to force authentication (enterprise mode)
- D3. Graceful degradation when auth is disabled
- D4. Configuration documented in environment setup

**Feature Gating Hook:**
```typescript
interface FeatureGateConfig {
  requireAuth?: boolean
  requireSupabase?: boolean
  featureFlag?: string
  fallback?: React.ReactNode
}

const useFeatureGate = (config: FeatureGateConfig) => {
  const { user, isAuthenticated } = useUser()
  const flags = useFeatureFlags()
  
  const isEnabled = useMemo(() => {
    if (config.featureFlag && !flags[config.featureFlag]) {
      return false
    }
    
    if (config.requireAuth && !isAuthenticated) {
      return false
    }
    
    if (config.requireSupabase && !flags.FEATURE_SUPABASE) {
      return false
    }
    
    return true
  }, [config, isAuthenticated, flags])
  
  return {
    isEnabled,
    Gate: ({ children }: { children: React.ReactNode }) => 
      isEnabled ? <>{children}</> : <>{config.fallback}</>
  }
}
```

**Work Preservation During Auth:**
```typescript
const preserveAndAuthenticate = async () => {
  // 1. Export current state to temporary storage
  const snapshot = await exportGraphState()
  sessionStorage.setItem('pre_auth_work', JSON.stringify(snapshot))
  
  // 2. Trigger authentication
  await signUp(email, password)
  
  // 3. After successful auth, restore work
  const preserved = sessionStorage.getItem('pre_auth_work')
  if (preserved) {
    await importGraphState(JSON.parse(preserved))
    sessionStorage.removeItem('pre_auth_work')
    
    // 4. Optionally auto-save to cloud
    if (autoSaveToCloud) {
      await saveToSupabase()
    }
  }
}
```

### Integration Instructions
To implement protected features and anonymous mode:

1. Wrap your app with AuthUserProvider (if using auth):
```typescript
import { AuthUserProvider } from '@promptscape/core/providers/AuthUserProvider';

<AuthUserProvider>
  <App />
</AuthUserProvider>
```

2. Use gated feature components:
```typescript
import { CloudSaveButton, LocalSaveButton } from '@promptscape/core/components/features/GatedFeatures';
import { WorkComplexityMonitor } from '@promptscape/core/components/upgrade/WorkComplexityMonitor';

<WorkComplexityMonitor nodeCount={nodes.length} edgeCount={edges.length}>
  <CloudSaveButton onClick={handleCloudSave}>Save to Cloud</CloudSaveButton>
  <LocalSaveButton onClick={handleLocalSave}>Save Locally</LocalSaveButton>
</WorkComplexityMonitor>
```

3. Configure environment variables:
```env
# Next.js
NEXT_PUBLIC_FEATURE_AUTH=true
NEXT_PUBLIC_FEATURE_SUPABASE=true
NEXT_PUBLIC_REQUIRE_AUTH=false
NEXT_PUBLIC_AUTH_OPTIONAL=true

# Vite
VITE_FEATURE_AUTH=true
VITE_FEATURE_SUPABASE=true
VITE_REQUIRE_AUTH=false
VITE_AUTH_OPTIONAL=true
```

4. Use feature gates programmatically:
```typescript
import { useFeatureGate } from '@promptscape/core/hooks/useFeatureGate';

const { isEnabled, Gate } = useFeatureGate({
  requireAuth: true,
  requireSupabase: true
});

<Gate fallback={<UpgradePrompt />}>
  <PremiumFeature />
</Gate>
```
