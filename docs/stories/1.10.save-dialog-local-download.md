# Story 1.10: save-dialog-local-download

## Status
Complete

## Story
**As a** user,
**I want** to save the current graph as a `.psg` file locally,
**so that** I can archive or share my work offline.

## Acceptance Criteria
1) Dialog UX
- A1. `SaveGraphDialog` allows naming the file and exporting a `.psg`.
- A2. Primary action disabled until valid name is entered; shows inline validation.

2) File correctness
- B1. Export uses `psgCodec.writePsg` with stable formatting and required fields.
- B2. Saved file round-trips via `Open` dialog without errors.

3) Validation and safety
- C1. Enforce `.psg` extension; sanitize/validate filename to disallow dangerous characters.
- C2. If validation fails, show friendly error and keep dialog open.

## Tasks / Subtasks
- Dialog and validation (A/C)
  - [x] Implement `SaveGraphDialog` UI with controlled name input (AC: A1–A2).
  - [x] Add filename validation and sanitization, enforce `.psg` extension (AC: C1–C2).
- Export (B)
  - [x] Serialize current graph (placeholder: stable JSON stringify until codec available) (AC: B1).
  - [x] Trigger browser download with correct MIME type (AC: B1).
  - [x] Verify re-open via `Open` dialog (round-trip via local parsing) (AC: B2).

## Dev Notes
- Implemented `SaveGraphDialog` in `packages/asset-browser/src/components/SaveGraphDialog.tsx`.
- Filename sanitization: trims, replaces spaces with dashes, removes unsafe characters; enforces `.psg` extension; inline validation; primary disabled until valid.
- Serialization placeholder: `JSON.stringify` stable formatting; to be replaced with `psgCodec.writePsg` when available.
- Download flow uses Blob + object URL; test hook `onSaveBlob` provided for assertions.
- Exported named in `src/index.tsx` as `SaveGraphDialog`.
- Keep logic shared with future remote saves to minimize duplication.

## Dependencies / Risks

- Risks: Filename handling across OSes; use conservative sanitization.
