# Story 1.31: Unified Prompt Parsing Improvements

## Summary
Enhanced the prompt parsing system to provide consistent behavior between the splash screen prompt dissector and the prompt wizard, with improved choice detection and better UX for node conversion.

## Changes Implemented

### 1. Convert to Weighted Choice Feature
- Added "Convert to Weighted Choice" option to the context menu for text nodes
- Automatically detects "or" patterns in text and creates appropriate weight distributions
- Provides quick conversion from simple text to choice nodes with proper weight distribution

### 2. Enhanced Prompt Parser
- Improved alternative detection with support for multiple separators:
  - `or` and `and` keywords
  - Forward slash (`/`) as alternative separator
  - Pipe (`|`) as alternative separator
- Smart detection of implicit choices in text
- Grammar-aware parsing for better node type detection

### 3. MiniMap Color Improvements
- Fixed red rendering issue in the minimap
- Updated to professional gray-scale palette with subtle color hints:
  - Text blocks: Medium gray (#606060)
  - Weighted choices: Gold-ish (#7a6a4a)
  - Variables: Purple-ish (#6a4a7a)
  - Output: Cyan-ish (#4a7a6a)
  - Post-it notes: Yellow-ish (#8a8a4a)
- Improved visibility with proper stroke colors

### 4. Clean Up Layout Integration
- Connected auto-layout functionality to canvas context menu
- Keyboard shortcut: ⌘⇧L for quick layout cleanup
- Smart selection-based cleanup (selected nodes vs all nodes)
- Visual feedback with toast notifications

### 5. Unified Prompt Parser
- Created `unifiedPromptParser.ts` for consistent parsing across the app
- Advanced pattern matching for various choice formats
- Support for list notation: `[option1, option2, option3]`
- Grammar-based enhancements for intelligent node type detection

## Usage Examples

### Converting Text to Weighted Choice
1. Right-click on any text node
2. Select "Convert to Weighted Choice" 
3. If text contains "or", it automatically creates options
4. Otherwise, creates a template with the text and an alternative

### Using Enhanced Parser
```typescript
// Automatically detects choices
"warrior or mage" → Choice node with 2 options
"red/blue/green" → Choice node with 3 options
"small | medium | large" → Choice node with 3 options
```

### Clean Up Layout
- Right-click on canvas → "Clean Up Layout" (or ⌘⇧L)
- Automatically arranges all nodes or selected nodes
- Uses intelligent layout algorithm based on graph structure
