# Story 1.2: Prompt Analysis & Node Generation

## Status
Approved

## Story
**As a** VFX artist,  
**I want** to paste a prompt and see it intelligently broken into inline-editable nodes,  
**so that** I can immediately start tweaking without leaving the canvas.

## Acceptance Criteria
1. Implement prompt parser that identifies semantic units
2. Create visual range indicators showing text-to-node mapping
3. Generated nodes appear in editing mode by default
4. Click anywhere on canvas to confirm all edits
5. Tab/Shift+Tab navigates between node edit fields
6. Support Escape key to cancel edits

### Technical Implementation Details
```typescript
interface PromptAnalysis {
  segments: Array<{
    text: string;
    startIndex: number;
    endIndex: number;
    suggestedNodeType: NodeType;
    confidence: number;
  }>;
  
  generateNodes(): EditableNode[];
  adjustBoundary(segmentId: string, newBounds: Range): void;
}
```

### Parsing Strategy
1. **Tokenization**: Split on punctuation and whitespace
2. **Classification**: Identify semantic units
   - Nouns/objects → TextBlock
   - Lists (comma-separated) → WeightedChoice
   - Descriptive phrases → TextBlock or Concat
3. **Grouping**: Combine related tokens
4. **Node Generation**: Create appropriate node types

### Integration Points
- Must work with React Flow's node positioning
- Integrates with keyboard shortcut system
- Connects to validation framework
- Preview system should update during parsing

### Example Parse
Input: "A weary merchant in tattered robes, carrying scrolls or books or potions"
Output:
- TextBlock: "A weary merchant"
- TextBlock: "in tattered robes"
- Concat: "carrying"
- WeightedChoice: ["scrolls", "books", "potions"]

### Rollback Procedures
1. **Feature Flag Rollback**: Parser behind flag `prompt-analysis-v2`
2. **Graceful Degradation**: Falls back to simple text node if parser fails
3. **UI Rollback**: Restore manual node creation UI if parser issues
4. **Emergency Procedure**:
   - Disable parser feature flag
   - Show manual node creation palette
   - Log parser failures for debugging
5. **User Communication**: Toast notification if parser unavailable

#### Security Considerations

1. **Input Validation**: All user inputs must be sanitized before storage/display
2. **DOM Manipulation**: Use React refs instead of querySelector where possible
3. **Event Handler Cleanup**: Ensure all event listeners are properly removed
4. **Content Security Policy**: Consider CSP headers for XSS protection

#### Performance Optimizations

1. **Virtual Scrolling**: For large node graphs, implement windowing
2. **Memoization**: Use React.memo for node components
3. **Batch Updates**: Group state changes to reduce re-renders
4. **Worker Thread**: Consider moving execution engine to Web Worker

#### Architecture Recommendations

1. **Command Pattern**: Implement undo/redo using command pattern
2. **Observer Pattern**: Use for cross-component communication
3. **Factory Pattern**: Create node factory for extensibility
4. **Dependency Injection**: Make engine testable with DI

#### Risk Assessment

- **High Risk**: XSS vulnerabilities in text inputs
- **Medium Risk**: Memory leaks from uncleared timeouts
- **Low Risk**: Performance degradation with many nodes
