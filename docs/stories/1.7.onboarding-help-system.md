# Story 1.7: Onboarding & Help System

## Status
Approved

## Story
**As a** first-time user,  
**I want** guided onboarding and contextual help,  
**so that** I can quickly understand and master inline editing without frustration.

## Acceptance Criteria
1. Interactive tutorial launches on first visit (skippable)
2. Medieval demo serves as the tutorial example
3. Contextual tooltips appear for key UI elements
4. Help overlay available via "?" key showing all shortcuts
5. Success celebration when user completes first edit
6. Progress indicators show tutorial completion
7. Help content accessible without leaving canvas
8. Tutorial can be replayed from settings

## Dev Notes
### Architecture Context
- Onboarding should be non-intrusive but discoverable
- Use React Context for tutorial state management
- Leverage existing medieval demo for consistency
- Performance: Tutorial overhead <50ms

### Technical Implementation Details
```typescript
interface TutorialStep {
  id: string;
  title: string;
  description: string;
  target: string; // CSS selector
  action: 'click' | 'drag' | 'type' | 'observe';
  validation: () => boolean;
  hint?: string;
}

interface OnboardingState {
  tutorialProgress: number;
  completedSteps: string[];
  achievementsUnlocked: string[];
  helpViewed: Record<string, boolean>;
  preferences: {
    showTooltips: boolean;
    enableCelebrations: boolean;
    keyboardShortcutsOverlay: boolean;
  };
}
```

### Tutorial Flow
1. Welcome screen with value proposition
2. Show empty canvas
3. Guide paste of medieval prompt
4. Highlight generated nodes
5. Guide first inline edit
6. Show preview update
7. Celebrate completion
8. Offer advanced features tour

### Accessibility Considerations
- Keyboard navigation for all tutorial steps
- Screen reader announcements for progress
- High contrast mode for overlays
- Reduced motion option

### Integration Points
- LocalStorage for persistence
- Analytics events for funnel tracking
- Settings system for preferences
- Medieval demo for content

### Rollback Procedures
1. **Feature Flag Rollback**: Tutorial behind flag `onboarding-v1`
2. **Graceful Degradation**: App fully functional without tutorial
3. **Quick Disable**: ESC key closes all help overlays
4. **Emergency Procedure**:
   - Hide all tutorial UI via feature flag
   - Clear localStorage tutorial state
   - Default to expert mode
5. **User Override**: Settings allow permanent disable

## Testing

- 80%+ users discover keyboard shortcuts
- <5% tutorial abandonment
- 95%+ can replay tutorial if needed
- Zero blocking issues reported
