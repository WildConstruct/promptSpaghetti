# Story 1.7: psg-codec-and-migration

## Status
Ready for Review

## Story
**As a** developer integrating the graph file format,
**I want** a validated `.psg` codec with legacy migration,
**so that** users can reliably open existing `.graph.json` files and save/load the new `.psg` format.

## Acceptance Criteria
1) Schema validation
- A1. The `.psg` schema is defined with zod and enforces required fields: `version`, `kind = "graph"`, `meta.id`, `meta.name`, `meta.createdAt`, `meta.updatedAt`, and `graph.nodes`/`graph.edges`.
- A2. `readPsg` throws structured validation errors listing invalid paths and reasons with PSGError interface.

2) Serialization
- B1. `writePsg` outputs stable, pretty-printed JSON (2-space indent).
- B2. Round-trip: `readPsg(writePsg(validPSG))` equals the original (ignoring field order).

3) Legacy migration
- C1. `fromLegacyGraph(name, graph)` returns a valid `PSGFile` when given a valid legacy `.graph.json`.
- C2. Migrated files pass `readPsg` and preserve nodes, edges, and basic layout.

4) Samples and fixtures
- D1. Provide at least 2 valid PSG samples and 2 invalid samples (missing required, wrong type).
- D2. Provide at least 1 legacy `.graph.json` fixture.

5) Tests
- E1. Unit tests cover: valid read, invalid read (assert error paths), write round-trip, legacy migration correctness.
- E2. Test names clearly map to ACs (A/B/C/D/E).

### Enhanced Error Handling Requirements

#### PSGError Interface
```typescript
interface PSGError {
  type: PSGErrorType;
  message: string;
  details?: any;
  suggestions?: string[];
}
```

#### PSGErrorType Enum
```typescript
enum PSGErrorType {
  INVALID_JSON = 'INVALID_JSON',
  INVALID_SCHEMA = 'INVALID_SCHEMA',
  CORRUPTED_DATA = 'CORRUPTED_DATA',
  VERSION_INCOMPATIBLE = 'VERSION_INCOMPATIBLE',
  FILE_TOO_LARGE = 'FILE_TOO_LARGE',
  MISSING_REQUIRED_FIELDS = 'MISSING_REQUIRED_FIELDS',
  INVALID_NODE_DATA = 'INVALID_NODE_DATA',
  INVALID_EDGE_DATA = 'INVALID_EDGE_DATA',
  SECURITY_VIOLATION = 'SECURITY_VIOLATION'
}
```

- **XSS Patterns**: Detect `javascript:`, `<script>`, `eval(`
- **File Size**: Default max 10MB, configurable
- **Data Consistency**: Validate all edge sources/targets exist in nodes
