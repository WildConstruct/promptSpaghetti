# Getting Started with Prompt Spaghetti Inline Editing

Welcome to Prompt Spaghetti's revolutionary inline editing system! This guide will help you master the interface and become productive in minutes.

## 🚀 Quick Start

### First Visit
When you first open Prompt Spaghetti, you'll be greeted with an interactive tutorial that walks you through the core features using our medieval fantasy demo. 

**To start the tutorial:**
1. Click "Start Tutorial" on the welcome screen
2. Or press `T` at any time to begin
3. Follow the glowing highlights and step-by-step instructions

**To skip the tutorial:**
- Click "Skip Tutorial" or press `Escape`
- You can always replay it later from Settings → Help & Tutorials

### The Medieval Demo
We use a medieval fantasy prompt as our example throughout the tutorial. This demonstrates:
- How to paste and parse complex prompts
- Node creation and connections
- Inline editing of text variations
- Preview generation with multiple seeds

## 📝 Core Features

### Inline Editing
The heart of Prompt Spaghetti is its inline editing capability. No more modal dialogs or separate panels!

**To edit a node:**
1. **Double-click** any text node on the canvas
2. The text becomes editable immediately
3. Make your changes
4. Press **Enter** to save or **Escape** to cancel

**Pro tips:**
- Tab/Shift+Tab to navigate between fields
- Ctrl/Cmd+Enter to save and move to next node
- Text automatically saves after 2 seconds of inactivity

### Visual Canvas
- **Pan**: Click and drag on empty space
- **Zoom**: Ctrl/Cmd + Plus/Minus or scroll wheel
- **Fit All**: Ctrl/Cmd + 0 to see all nodes
- **Select**: Click nodes or drag to box-select multiple

### Node Management
- **Create**: Drag node types from the palette
- **Connect**: Drag from output to input ports
- **Delete**: Select and press Delete/Backspace
- **Duplicate**: Select and press Ctrl/Cmd + D
- **Arrange**: Nodes auto-arrange for clarity

## ⌨️ Keyboard Shortcuts

Press `?` at any time to see all available shortcuts. Here are the essentials:

### Editing
- `Double Click` - Edit node text inline
- `Enter` - Save current edit
- `Escape` - Cancel current edit
- `Tab` - Move to next field
- `Shift+Tab` - Move to previous field

### Navigation
- `Click+Drag` - Pan around canvas
- `Ctrl/Cmd+Plus` - Zoom in
- `Ctrl/Cmd+Minus` - Zoom out
- `Ctrl/Cmd+0` - Fit all nodes in view
- `Ctrl/Cmd+F` - Search nodes

### Selection & Creation
- `Ctrl/Cmd+A` - Select all nodes
- `Ctrl/Cmd+Click` - Add to selection
- `Ctrl/Cmd+D` - Duplicate selected
- `Delete/Backspace` - Delete selected
- `Ctrl/Cmd+Z` - Undo
- `Ctrl/Cmd+Shift+Z` - Redo

### Preview & Export
- `Ctrl/Cmd+P` - Generate preview
- `Ctrl/Cmd+E` - Export graph
- `Ctrl/Cmd+S` - Save project
- `Space` - Quick preview (hold)

### Help & UI
- `?` - Show keyboard shortcuts
- `H` - Toggle help panel
- `T` - Restart tutorial
- `Ctrl/Cmd+B` - Toggle sidebar

## 🎯 Your First Workflow

### 1. Create Your First Graph
1. **Paste a prompt**: Copy any text prompt and paste it on the canvas
2. **Auto-parse**: Prompt Spaghetti automatically creates nodes

### 2. Edit Inline
1. **Double-click** any text node
2. **Type** your variations
3. **Press Enter** to save

### 3. Generate Variations
1. **Add variations**: Click "+" in any text node
2. **Set weights**: Adjust probability for each variant
3. **Preview**: Press Ctrl/Cmd+P to see results
4. **Export**: Press Ctrl/Cmd+E when satisfied

## 🚨 Troubleshooting

### Common Issues

**Tutorial won't start:**
- Clear browser cache
- Check localStorage is enabled
- Try incognito/private mode
- Reset from Settings

**Keyboard shortcuts not working:**
- Check you're not in an input field
- Verify no browser extensions conflict
- Try different browser
- Check keyboard language

**Performance issues:**
- Reduce number of visible nodes
- Disable animations in Settings
- Update graphics drivers
- Use Chrome/Firefox for best performance
