# Docs Archive

This folder contains historical or low-priority documentation retained for context. Active docs remain in topic folders like `stories/`, `prd/`, `qa/`, `architecture/`.

Subfolders
- agent-tips/: historical automation/test detective notes
- epic1/: EPIC 1 era reviews and summaries
- automation/: older automation guides and summaries
- research/: one-off research notes and experiments
- reports/: technical debt reports, debug logs summaries

Move items back if revived; otherwise, keep here to reduce noise.
