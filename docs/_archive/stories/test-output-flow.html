🧪 Output Node → Preview Panel Test Guide

1. VERIFY OUTPUT NODE EXISTS
  • ✓ Check if at least one Output node is in the graph
  • ✓ Output nodes should appear with label "Output"
  • ✓ Output nodes are LOCKED (read-only) by design
  • → If missing: Drag an Output node from the palette
2. CHECK NODE CONNECTIONS
  • ✓ Verify Output node has incoming edge(s)
  • ✓ Source node (TextBlock, WeightedChoice, etc.) connects to Output
  • ✓ Edge should be visible as a line between nodes
  • → To connect: Drag from source node's output handle to Output node's input handle
3. TEST EXECUTION FLOW
  • ✓ Add a TextBlock node with text: "Hello World"
  • ✓ Connect TextBlock → Output node
  • ✓ Preview panel should show "Hello World" after ~300ms
  • ✓ Multiple seeds should show same result for deterministic nodes
4. PREVIEW PANEL VISIBILITY
  • ✓ Preview panel should be visible on the right side
  • ✓ Check for loading spinner during execution
  • ✓ Results appear under seed numbers (e.g., "Seed: 1234")
  • → If hidden: Press 'P' key or toggle preview button
5. CONSOLE DIAGNOSTICS

Open browser DevTools console and check for:

  • console.log from PreviewEngine updates
  • console.error for execution failures
  • console.warn for validation issues

COMMON ISSUES & FIXES
  • ❌ "No output node found" → Add an Output node
  • ❌ Preview empty → Check edges are connected
  • ❌ Preview not updating → Check debounce delay (300ms default)
  • ❌ Graph validation failed → Check for cycles or invalid connections
