# Story 6.1: Project File Structure & Management

## Status

In Progress

## Story

**As a** user of the prompt-spaghetti application,
**I want** a comprehensive project file management system with .psg file format support,
**so that** I can save, load, and organize my graph projects efficiently with proper version control and unsaved changes protection.

## Acceptance Criteria

1. **File Format Definition**: Application implements a .psg (PromptSpaghetti Graph) JSON-based file format with schema validation, versioning metadata, and serialization/deserialization utilities

2. **Save Project Functionality**: Users can save current graph projects using "Save" and "Save As" options with keyboard shortcuts (Ctrl+S/Cmd+S), file name sanitization, and success/failure notifications

3. **Open Project Functionality**: Users can open .psg files through file browser dialog, drag-and-drop onto canvas, with schema version compatibility checking and validation error handling

4. **Recent Projects Feature**: Application maintains a list of 5 most recently accessed projects with metadata (name, last access date, thumbnail) accessible through "Recent Projects" menu

5. **Unsaved Changes Management**: System tracks project "dirty" state and shows confirmation dialogs when closing browser or opening new projects with unsaved changes

6. **Project State Integration**: File operations properly integrate with existing graph state management, undo/redo system, and canvas reset functionality
