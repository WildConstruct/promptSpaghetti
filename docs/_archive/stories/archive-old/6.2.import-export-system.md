# Story 6.2: Import & Export System

## Status

Draft

## Story

**As a** user of the prompt-spaghetti application,
**I want** a comprehensive import and export system supporting multiple formats (JSON, PNG, text),
**so that** I can share my work, create backups, generate visual documentation, and integrate with external tools.

## Acceptance Criteria

1. **Export System Architecture**: Application implements a plugin-based ExportManager with abstract Exporter interface, progress reporting, and extensible format support through toolbar menu options

2. **JSON Export Implementation**: Users can export complete graph data to formatted JSON files with metadata, selective export options, and download functionality for backup and sharing purposes

3. **PNG Export Implementation**: Users can export visual representations of graphs to PNG files with zoom level handling, custom backgrounds, optional watermarks, and cross-browser rendering consistency

4. **Text Export Implementation**: Users can export generated prompts to text files with batch generation (multiple seeds), configurable formatting, and platform-specific line endings

5. **Import Validation System**: Application validates imported files with progressive validation (quick → thorough), detailed error reporting, schema migration for older formats, and recovery options

6. **Import UI Integration**: Users can import files through File menu with format filtering, validation error summaries, automatic fix suggestions, and "import anyway" options for non-critical issues

7. **Format Extension Support**: System supports importing existing VFX export formats and GeneratorBundle formats while maintaining backward compatibility with existing export functionality

## Dev Notes

### Architecture Context

**Integration with Existing Export Systems:**

- **Existing VFXExporter**: `packages/core/services/VFXExporter.ts` handles VFX-ready exports with ControlNet parameters
- **Server Exporter**: `server/src/exporter.ts` provides GeneratorBundle format conversion
- **HybridExportService**: Supports hybrid prompting export structures from Epic 8.6
- **New ExportManager**: Will orchestrate all export formats while maintaining existing functionality

[Source: packages/core/services/VFXExporter.ts, server/src/exporter.ts]

**Plugin Architecture Design:**

- **IExporter Interface**: Standard interface for all export formats (export(), validate(), getOptions())
- **ExportManager**: Central coordinator that registers and manages different exporters
- **Progress Reporting**: Standardized progress interface for long-running export operations
- **Format Detection**: Automatic detection of file formats for import operations

**File Format Specifications:**

- **JSON Export**: Complete graph serialization using existing GraphSchema patterns
- **PNG Export**: Visual canvas export using dom-to-image or html2canvas libraries
- **Text Export**: Execute graph and export generated prompts with formatting options
- **Import Validation**: Zod schema validation with migration support for older formats

[Source: packages/core/graphSchema.ts patterns]

### Source Tree Integration Points

**Core Package Structure:**

- **Managers**: `packages/core/managers/ExportManager.ts`, `ImportManager.ts`
- **Exporters**: `packages/core/exporters/` directory for format-specific implementations
- **Interfaces**: `packages/core/interfaces/IExporter.ts` for standardized export interface
- **Components**: Export/import dialogs and progress components in `packages/core/components/`
- **Integration**: Update `packages/core/GraphEditor.tsx` toolbar and menus

[Source: docs/architecture/source-tree.md]

**Technology Stack Integration:**

- **React 18**: Export/import UI components with hooks and context
- **TypeScript**: Full type safety for export/import operations
- **Zod**: Schema validation for import file format checking
- **Canvas API**: PNG export functionality with dom-to-image library
- **File Download**: Browser download API for file generation and saving

[Source: docs/architecture/tech-stack.md]

**Existing System Dependencies:**

- **Graph State**: Zustand store integration for accessing current graph data
- **Executor**: Use existing graph executor for text export functionality
- **VFX Services**: Integration with existing VFXExporter and HybridExportService
- **Project Manager**: Coordination with file management from Story 6.1
- **Validation**: Extend existing validation utilities from `packages/core/validation.ts`

### Key Technical Considerations

1. **Performance**: Handle large graphs efficiently with streaming and progress reporting
2. **Browser Compatibility**: Ensure canvas export works across all major browsers
3. **File Size Limits**: Handle browser download limits and chunked exports for large files
4. **Memory Management**: Proper cleanup of canvas elements and temporary objects
5. **Format Versioning**: Support migration between different export format versions
6. **Error Recovery**: Graceful handling of partial imports and corruption detection

### Integration with Epic 8 VFX Systems

**Existing VFX Export Capabilities:**

- **ControlNet Parameters**: Pose guidance, depth maps, edge detection, animation sequences
- **Camera Parameters**: FOV, aspect ratio, near/far planes from existing VFXExporter
- **Hybrid Prompting**: Integration with HybridExportService for advanced prompting methodologies
- **GeneratorBundle**: Compatibility with existing server export format

**Extension Strategy:**

- Maintain all existing VFX export functionality through VFXExporter
- Add new general-purpose formats (JSON, PNG, text) through ExportManager
- Provide unified export UI that includes both VFX and general export options
- Ensure backward compatibility with all existing export endpoints and formats

[Source: packages/core/services/VFXExporter.ts, server/src/exporter.ts]
