# Asset - Asset Generator Shortcut

## Command
`/asset`

## Target
`.bmad-core/agents/asset-generator.yaml`

## Description
Quick access to Asset Generation Specialist (Aspen)

## Usage
```
/asset
```

Then use commands like:
- `*plan` - Present generation plan
- `*generate-batch` - Convert list to PSG assets
- `*migrate` - Move to asset browser
- `*combine` - Create combinations
- `*export` - Export assets
