# Responsive Framework Guide

The UI Kit provides a comprehensive responsive framework for building adaptive interfaces across all platforms.

## Breakpoint System

### Standard Breakpoints

The framework uses a mobile-first approach with 6 standard breakpoints:

| Breakpoint | Min Width | Target Devices                        |
| ---------- | --------- | ------------------------------------- |
| `xs`       | 0px       | Extra small devices (portrait phones) |
| `sm`       | 576px     | Small devices (landscape phones)      |
| `md`       | 768px     | Medium devices (tablets)              |
| `lg`       | 1024px    | Large devices (desktops)              |
| `xl`       | 1280px    | Extra large devices (large desktops)  |
| `xxl`      | 1536px    | Extra extra large devices             |

### Using Breakpoints

```tsx
import { useBreakpointValue, getCurrentBreakpoint } from '@prompt-spaghetti/ui-kit';

// Get current breakpoint
const breakpoint = getCurrentBreakpoint(window.innerWidth);

// Use responsive values
const columns = useBreakpointValue(
  {
    xs: 1,
    sm: 2,
    md: 3,
    lg: 4,
  },
  1
); // default value
```

## Grid System

### Basic Grid

```tsx
import { Grid, Row, Col } from '@prompt-spaghetti/ui-kit';

<Row spacing={2}>
  <Col xs={12} md={6} lg={4}>
    Column 1
  </Col>
  <Col xs={12} md={6} lg={4}>
    Column 2
  </Col>
  <Col xs={12} md={12} lg={4}>
    Column 3
  </Col>

```

### Container

```tsx
import { Container } from '@prompt-spaghetti/ui-kit';

// Fixed max-width container
<Container maxWidth="lg" fixed>
  Your content here
</Container>

// Responsive container
<Container maxWidth="xl">
  Responsive content
</Container>
```

## Adaptive Components

### Collapsible Panels

Panels that can automatically collapse based on viewport:

```tsx
import { CollapsiblePanel } from '@prompt-spaghetti/ui-kit';

<CollapsiblePanel title="Mobile Collapsible" collapseOn={['xs', 'sm']} defaultOpen={true}>
  This panel collapses on mobile devices
</CollapsiblePanel>;
```

### Adaptive Layout

Complete layout system with responsive sidebar:

```tsx
import { AdaptiveLayout } from '@prompt-spaghetti/ui-kit';

<AdaptiveLayout
  sidebar={<Sidebar />}
  sidebarCollapseOn={['xs', 'sm']}
  main={<MainContent />}
  header={<Header />}
  footer={<Footer />}
/>;
```

### Responsive Tabs

Tabs that stack on small screens:

```tsx
import { ResponsiveTabs } from '@prompt-spaghetti/ui-kit';

<ResponsiveTabs
  tabs={[
    { id: 'tab1', label: 'Tab 1', content: <Tab1 /> },
    { id: 'tab2', label: 'Tab 2', content: <Tab2 /> },
  ]}
  stackOn={['xs', 'sm']}
/>;
```

## Device Detection

### Enhanced Device Info

```tsx
import { useDeviceDetection } from '@prompt-spaghetti/ui-kit';

const { isMobile, isTablet, isDesktop, isTouch, isRetina, isPortrait, isIOS, isAndroid, device } = useDeviceDetection();

// Conditional rendering
if (isMobile) {
  return <MobileView />;
}
```

### Performance Features

Automatically adjust features based on device capabilities:

```tsx
import { getPerformanceFeatures } from '@prompt-spaghetti/ui-kit';

const features = getPerformanceFeatures();

// Features include:
// - enableAnimations
// - enableParallax
// - enableBlur
// - maxConcurrentAnimations
// - debounceDelay
```

## Responsive Utilities

### Responsive Classes

```tsx
import { responsiveClasses } from '@prompt-spaghetti/ui-kit';

const className = responsiveClasses('button', {
  xs: 'button-small',
  md: 'button-medium',
  lg: 'button-large',
});
```

### Visibility Control

```tsx
import { useVisibility } from '@prompt-spaghetti/ui-kit';

// Show only on desktop
const showOnDesktop = useVisibility({
  showOn: ['lg', 'xl', 'xxl'],
});

// Hide on mobile
const hideOnMobile = useVisibility({
  hideOn: ['xs', 'sm'],
});
```

### Container Queries

```tsx
import { useContainerQuery } from '@prompt-spaghetti/ui-kit';

const containerRef = useRef();
const queries = useContainerQuery(containerRef, {
  small: 300,
  medium: 600,
  large: 900,
});

<div ref={containerRef}>{queries.large ? <LargeView /> : <CompactView />}</div>;
```

## Best Practices

1. **Mobile-First Design**: Start with mobile layouts and enhance for larger screens
2. **Touch Targets**: Ensure minimum 44px touch targets on mobile devices
3. **Performance**: Use device detection to disable heavy features on low-end devices
4. **Accessibility**: Maintain keyboard navigation across all breakpoints
5. **Testing**: Test across all major breakpoints and device types

## Migration Guide

### From Legacy ResponsiveValue

```tsx
// Old
type ResponsiveValue<T> =
  | T
  | {
      mobile?: T;
      tablet?: T;
      desktop?: T;
    };

// New (with backward compatibility)
type ResponsiveValueEnhanced<T> =
  | T
  | {
      xs?: T;
      sm?: T;
      md?: T;
      lg?: T;
      xl?: T;
      xxl?: T;
    };
```

### Breakpoint Mapping

- `mobile` → `xs` or `sm`
- `tablet` → `md`
- `desktop` → `lg`, `xl`, or `xxl`
