# UI Kit - Cross-Platform React Components

Welcome to the **UI Kit** component library! This library provides a comprehensive set of cross-platform React components designed specifically for graph editing applications.

## 🎯 Key Features

- **Cross-Platform**: Components work seamlessly across Web, Mobile, and Desktop platforms
- **Graph-Focused**: Specialized components for node-based graph editing
- **Responsive Design**: Mobile-first approach with adaptive layouts
- **Theme System**: Complete theming support with light/dark modes
- **Accessibility**: Built-in accessibility features and keyboard navigation
- **TypeScript**: Full TypeScript support with comprehensive type definitions
- **Tested**: Comprehensive test coverage with Jest and React Testing Library

## 📦 Components

### Base Components

- **Button** - Versatile button with multiple variants and states
- **Input/TextArea** - Form inputs with validation and icons
- **Card** - Container component with header, content, and footer
- **Modal** - Accessible modal dialog with focus management
- **Layout** - Flex, Grid, Stack, and Container layout components

### Graph Components

- **GraphCanvas** - Interactive graph visualization and editing
- **NodePalette** - Drag-and-drop node palette with search
- **InspectorPanel** - Property editor for selected nodes

### Platform Adapters

- **WebAdapter** - Web-specific optimizations and APIs
- **ReactNativeAdapter** - React Native optimizations and APIs
- **PlatformProvider** - Context for platform-specific functionality

## 🎨 Theming

The UI Kit includes a comprehensive theming system:

```tsx
import { ThemeProvider } from '@prompt-spaghetti/ui-kit';

function App() {
  return <ThemeProvider defaultColorMode="system">{/* Your app components */}</ThemeProvider>;
}
```

### Theme Features

- Light and dark mode support
- System preference detection
- Custom color schemes
- Responsive breakpoints
- CSS custom properties
- Runtime theme switching

## 🌍 Cross-Platform Usage

Components automatically adapt to different platforms:

```tsx
import { PlatformProvider, Button } from '@prompt-spaghetti/ui-kit';

function App() {
  return (
    <PlatformProvider platform="web">
      <ThemeProvider>
        <Button hapticFeedback="light">Platform-aware Button</Button>
      </ThemeProvider>
    </PlatformProvider>
  );
}
```

### Platform Features

- Automatic platform detection
- Platform-specific optimizations
- Touch vs. mouse interactions
- Haptic feedback on mobile
- Keyboard shortcuts on desktop
- Native look and feel

## 📱 Responsive Design

All components are designed with mobile-first responsive principles:

- **Breakpoints**: Mobile (< 768px), Tablet (768px - 1024px), Desktop (> 1024px)
- **Touch Targets**: Minimum 44px touch targets on mobile
- **Gestures**: Pinch-to-zoom, pan, and touch interactions
- **Layout**: Automatic layout adaptation for different screen sizes

## ♿ Accessibility

Built-in accessibility features include:

- ARIA labels and roles
- Keyboard navigation
- Focus management
- Screen reader support
- High contrast mode support
- Reduced motion preferences

## 🚀 Getting Started

1. Install the package:

```bash
npm install @prompt-spaghetti/ui-kit
```

2. Wrap your app with providers:

```tsx
import { PlatformProvider, ThemeProvider } from '@prompt-spaghetti/ui-kit';

function App() {
  return (
    <PlatformProvider>
      <ThemeProvider>{/* Your app */}</ThemeProvider>
    </PlatformProvider>
  );
}
```

3. Use components:

```tsx
import { Button, Input, GraphCanvas } from '@prompt-spaghetti/ui-kit';
```

## 🧪 Testing

The library includes comprehensive testing utilities:

```tsx
import { render, screen } from '@testing-library/react';
import { Button, ThemeProvider } from '@prompt-spaghetti/ui-kit';

test('renders button', () => {
  render(
    <ThemeProvider>
      <Button>Click me</Button>
    </ThemeProvider>
  );

  expect(screen.getByRole('button')).toBeInTheDocument();
});
```
